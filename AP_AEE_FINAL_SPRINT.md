## The loop (test-driven — theory is only a patch tool)
> SOLVE → DIAGNOSE → PATCH → RETEST

1. **SOLVE** questions first (PYQ / subject test / mock). Solving is the activity, not theory.
2. **DIAGNOSE** — after every test, pull the HTML source, extract every miss, log it. A test with no analysis is a wasted test.
3. **PATCH** — study only the concepts behind your misses, 20–30 min each, within 24 h.
4. **RETEST** — redo the missed questions until clean; the next test must cover patched areas.
