### 🔰 PREREQUISITE: Understanding Magnetism First

Before we can understand a transformer, you need to know:

**Magnetic Flux (Φ) — What is it?**
- Imagine magnetic field lines like invisible lines coming from a magnet's North pole to South pole
- **Flux** = how many of these field lines pass through a surface
- Unit: **Weber (Wb)** — think of it as "quantity of magnetism"
- More lines = more flux = stronger magnetic field

**Flux Density (B) — How concentrated is it?**
- B = Φ / A (flux per unit area)
- Unit: **Tesla (T)**
- Bigger magnet with same flux = lower flux density
- Like crowd density — same number of people, smaller room = denser crowd

**Electromagnetism — How to make a magnet with electricity:**
- When current flows through a wire, it creates a magnetic field
- Coil the wire into loops (turns) = magnetic field gets stronger
- More turns = stronger magnet
- Iron core inside coil = magnetic field gets MUCH stronger (iron is "magnetic" — it helps concentrate the field)

**Faraday's Law — The Foundation of Transformers:**
> *"A changing magnetic field through a coil induces a voltage in that coil"*

Mathematically:
```
Induced EMF (E) = N × (change in flux / change in time)
                = N × dΦ/dt

Where N = number of turns in the coil
```

**Lenz's Law — Direction of induced voltage:**
- The induced voltage creates a current whose magnetic field OPPOSES the original change
- Nature always resists change

### FORMULA 1: EMF Equation (E = 4.44 × f × N × Φm)

#### Why This Formula Exists:

**Step 1 — Let's Build It From Scratch:**

```
1. We have a transformer with N turns on primary winding
2. We apply AC voltage (50 Hz in India = voltage changes direction 50 times per second)
3. This AC voltage causes AC current to flow
4. AC current creates a CHANGING magnetic field (since current is changing)
5. This changing magnetic field passes through the iron core
6. According to Faraday's Law: changing flux through a coil induces voltage
7. The induced voltage is E (this is what we want to calculate)
```

**Step 2 — The Math (Don't Panic — I'll Walk Through Every Step):**

The voltage applied is sinusoidal (sine wave):
```
V = Vm x sin(wt)
```

The flux in the core is also sinusoidal (it follows the voltage):
```
Phi = Phim x sin(wt)
```

Faraday's Law says: E = N x d(Phi)/dt

So let's find d(Phi)/dt:
```
Phi = Phim x sin(wt)
d(Phi)/dt = Phim x omega x cos(wt)
```

This is the **instantaneous** rate of change of flux.

Now we need to find the **average voltage** induced over half a cycle (positive half, from 0 to π).

#### The Key Insight — What Does "Average Rate of Change" Mean?

**Instantaneous rate of change** = dΦ/dt = how fast flux is changing RIGHT NOW
**Average rate of change** = total change in flux / time taken

The confusion comes from: over the full half-cycle, net change in flux is actually **ZERO** (starts at 0, ends at 0). But that's misleading.

**What we actually mean:** The average rate at which flux CHANGES as it goes from 0 → Φm → 0 over the half cycle.

Think of it this way:
```
          Φ
          ↑
    Φm    |‾‾‾‾‾‾‾‾‾‾
          |         ‾‾‾‾‾‾ Φm (at peak)
          |       ‾‾          ‾‾
          |     ‾‾              ‾‾
          |   ‾‾                  ‾‾
    0     |_‾‾____________________‾‾‾‾→ t
          0   π/2ω              π/ω
           ←────── T/2 ──────────→
           
Time T/2 = π/ω (half the full period)
```

**Step-by-Step Calculation:**

```
Step 1: How much time is the half cycle?
   Full period T = 2π/ω
   Half period = T/2 = π/ω seconds

Step 2: What is the total "change" in flux to consider?
   
   Think of it like a car trip:
   - Car goes from 0 km/h to 100 km/h (accelerates)
   - Then from 100 km/h back to 0 km/h (decelerates)
   - Net velocity change = 0
   - But average SPEED isn't zero!
   
   Similarly for flux:
   - Flux rises from 0 to Φm (change = +Φm)
   - Then falls from Φm to 0 (change = -Φm)
   - Total "distance traveled" = Φm + Φm = 2Φm
   
   We use the TOTAL change (not net), because the induced EMF 
   depends on how fast the flux is "cutting" through the coils

Step 3: Calculate average rate of change
   
   Average dΦ/dt = Total change in flux / Time
                 = 2Φm / (π/ω)
                 = 2ωΦm / π
```

**Visual Verification:**

```
Let's check dimensions: Φm is in Weber, ω is in rad/s, so:
  2ωΦm/π = 2 × (rad/s) × (Wb) / π = Wb/s = V (for 1 turn) ✓
```

**Why This Makes Physical Sense:**

```
At the START of the half-cycle (t = 0):
  dΦ/dt = ωΦm cos(0) = ωΦm (MAXIMUM) → flux changing very fast

At the MIDDLE of the half-cycle (t = π/2ω):
  dΦ/dt = ωΦm cos(π/2) = 0 → flux changing zero! (peak of sine)

At the END of the half-cycle (t = π/ω):
  dΦ/dt = ωΦm cos(π) = -ωΦm (MINIMUM, negative) → flux changing backwards

The instantaneous rate varies from +ωΦm → 0 → -ωΦm
The AVERAGE of this over the half-cycle = 2ωΦm/π

You can verify with calculus:
  Average of cos(ωt) from 0 to π = [sin(ωt)/ω] from 0 to π / (π/ω)
                                 = [sin(π) - sin(0)] / (π/ω)
                                 = 0 / (π/ω) = 0  ← wait, that's not right

Actually let me recalculate properly:
The formula Φ = Φm sin(ωt) means dΦ/dt = ωΦm cos(ωt)

But the FLUX itself goes: 0 → Φm → 0
We want the average RATE at which flux CUTS through the coil
This is the average of |dΦ/dt| over the half cycle

Average of |cos(θ)| from 0 to π = (2/π) ≈ 0.636
So average |dΦ/dt| = 0.636 × ωΦm = (2/π) × ωΦm ✓

Confirmed: Average dΦ/dt = 2ωΦm/π
```

**The Clean Math:**

```
Average rate of change = integral from 0 to pi of |d(Phi)/dt| d(wt)

But since d(Phi)/dt = omega x Phim x cos(wt) and cos is positive from 0 to pi/2,
and we're considering half cycle:

  Average |d(Phi)/dt| = (1/pi) x [Area under |cos| curve from 0 to pi]
                 = (1/pi) x 2 x [Area from 0 to pi/2]
                 = (1/pi) x 2 x [sin(theta)]_0 to pi/2
                 = (1/pi) x 2 x [1 - 0]
                 = 2/pi

  So: Average |d(Phi)/dt| = (2/pi) x omega x Phim = 2 x omega x Phim / pi
```

**So Average EMF:**
```
E_avg = N x (2 x omega x Phim / pi) = 2 x N x omega x Phim / pi
```

**Root Mean Square (RMS) value:**
RMS is the "effective" value of AC. It's the DC equivalent that would do the same work.

For a sine wave:
```
E_rms = E_avg / Form Factor = (2 x N x omega x Phim / pi) / 1.11
      = (2 x N x omega x Phim) / 3.49
```

Wait, let me recalculate properly. There's a cleaner way:

The form factor (RMS/AVG) for a sine wave = pi/(2 x sqrt(2)) = 1.11

So:
```
E_rms = N x omega x Phim x (2/pi) x (pi/(2 x sqrt(2)))
E_rms = N x omega x Phim / sqrt(2)
```

But omega = 2 x pi x f, so:
```
E_rms = N x 2 x pi x f x Phim / sqrt(2)
      = sqrt(2) x pi x f x N x Phim
```

```
E_rms = 4.44 x f x N x Phim
```

**THERE IT IS - THE 4.44 FACTOR!**

The derivation shows:
```
E_rms = N x [2 x pi x f]  x Phim x [1/sqrt(2)]
        from omega=2pif         RMS conversion
```

```
E_rms = N x (2pi/sqrt(2)) x f x Phim
      = N x (2pi/sqrt(2)) x f x Phim
      where (2pi/sqrt(2)) = 4.44
```

**The simplification:**
```
2pi/sqrt(2) = (2 x 3.1416) / 1.4142 = 6.283 / 1.414 = 4.44
```

So:
```
4.44 = 2pi/sqrt(2) = pi x sqrt(2) = 3.14 x 1.414 = 4.44
```

**Is 4.44 = pi/sqrt(2)? Let's check:**
```
pi/sqrt(2) = 3.14/1.414 = 2.22  (NOT 4.44!)
```

**So the correct statement is:**
```
4.44 = 2pi/sqrt(2) = pi x sqrt(2) = 4.44
```

---

#### Understanding the "Factors" Confusion:

```
Factor                 Formula              Value     What it is
----------------------------------------------------------------------
Form Factor (FF)      RMS / Average        1.11      Ratio of RMS to average
Peak Factor (PF)      Peak / RMS           1.414     Ratio of peak to RMS
```

**Product of Form Factor x Peak Factor:**
```
FF x PF = 1.11 x 1.414 = 1.57 = pi/2
```

**So 4.44 is NOT equal to (Form Factor) x (Peak Factor)**

The 4.44 comes from the full derivation, combining:
1. The **2pi** from the angular frequency omega = 2pif
2. The **1/sqrt(2)** from the RMS conversion

```
4.44 = 2pi/sqrt(2) = pi x sqrt(2) = 3.14 x 1.414 = 4.44
```

#### Why is 4.44 Important?

```
If waveform is...       The constant changes
-------------------------------------------------
Sine wave               4.44  <- this is for transformers
Square wave             4.00
Triangular              2.00
Half-wave rectified     2.22
```

**4.44 is UNIQUE to sinusoidal waveforms** — it comes from the specific geometry of a sine wave's rate of change.

#### Step 3 — Real Life Anchor:

> Every 11 kV/415 V distribution transformer you see on Indian poles works exactly this way. The 50 Hz AC from the grid creates a changing magnetic field in the core. This changing field induces 415 V on the output side.
>
> **The 4.44 is the "sine wave tax"** — it's the price you pay for using AC instead of DC. For the same average flux change, a DC generator would give you E_avg = 2ωΦm/π, but for AC we want RMS, which is 4.44× that. The extra factor of √2 (~1.414) converts peak to RMS.

---

#### 🔌 Understanding the "Sine Wave Tax" Explained:

**Think of it like this:**

```
DC Generator Output:
  → Gives you a STEADY voltage (straight line)
  → If DC voltage = 100V, you get 100V all the time
  → Easy to measure: just use a voltmeter
  → The "value" = 100V (this is like the average)

AC Generator Output:
  → Gives you a SINE WAVE (goes up and down)
  → Peaks at +141V, dips to -141V
  → A voltmeter shows ~100V (the RMS value)
  → But the PEAK is 141V!

Why RMS and not just average?
  → For HEATING EFFECT, what matters is RMS, not average
  → A 100V DC heater and a 100V RMS AC heater give SAME heat
  → That's why we use RMS — it measures the "effective" value

So the "tax" is:

  DC generator:    E_avg = 2ωΦm/π  (just the average, no extra math)

  AC generator:    E_rms = 4.44 × f × N × Φm
                   = (2ωΦm/π) × √2
                   = E_avg × 1.414
                   = E_avg × "the RMS tax"

  The √2 (~1.414) is the "RMS conversion tax" you pay for using AC!
```

**Simple analogy (CORRECTED):**

```
Imagine people passing through a door:

DC = Steady flow of 10 people/second ALWAYS forward
AC = People slosh back and forth:
     At peak forward:  14.14 people rush forward
     At zero crossing: 0 people moving
     At peak backward: 14.14 people rush backward
     (All at the SAME instant!)

RMS = Root Mean Square:

Step 1 - SQUARE (removes direction):
  14.14² = 200,  0² = 0,  14.14² = 200

Step 2 - MEAN (average):
  (200 + 0 + 200 + 0) / 4 = 50

Step 3 - SQUARE ROOT:
  √50 = 7.07... wait that's not right either.

Let me redo properly:

If DC equivalent = 10 people (what we want):
  RMS = 10 means heating effect = 10² = 100

For AC to give same heating:
  Peak must be: Peak = DC_equivalent x √2 = 10 x 1.414 = 14.14

So:
  DC: 10 people always gives heating = 100
  AC: Peak 14.14 people at any instant gives RMS = 14.14/√2 = 10 ✓

The √2 "tax" converts PEAK to RMS (effective) value.
```

**Key insight:** AC doesn't split into "half forward, half backward" at the same time. At ANY instant, ALL the current flows the SAME direction (forward or backward). The √2 factor converts the PEAK to RMS.

```

#### Practice Questions:

**Q1 (Easy):** A 50 Hz transformer has 1000 turns on primary, 200 turns on secondary. Core cross-section = 100 cm², maximum flux density = 1.2 Tesla. Find the primary and secondary EMFs.

**Solution:**
```
Given:
  f = 50 Hz
  N₁ = 1000, N₂ = 200
  A = 100 cm² = 0.01 m²
  Bm = 1.2 T

Step 1: Find flux
  Φm = Bm × A = 1.2 × 0.01 = 0.012 Wb

Step 2: Apply EMF equation
  E₁ = 4.44 × 50 × 1000 × 0.012
      = 4.44 × 50 × 12
      = 4.44 × 600 = 2664 V

  E₂ = 4.44 × 50 × 200 × 0.012
      = 4.44 × 50 × 2.4
      = 4.44 × 120 = 533 V

Step 3: Check ratio
  E₁/E₂ = 1000/200 = 5:1 ✓
  Actual ratio = 2664/533 ≈ 5:1 ✓
```

**Q2 (Medium):** A 2300V/230V, 50 Hz transformer has 200 turns on secondary. Find the number of turns on primary and core flux if the flux density should not exceed 1.2 T and core area is 80 cm².

**Solution:**
```
Given:
  V₁ = 2300 V, V₂ = 230 V (rated)
  N₂ = 200 turns
  Bmax = 1.2 T, A = 80 cm² = 0.008 m²

Step 1: Turns ratio
  V₁/V₂ = N₁/N₂
  2300/230 = N₁/200
  10 = N₁/200
  N₁ = 2000 turns

Step 2: Core flux
  Φm = B × A = 1.2 × 0.008 = 0.0096 Wb

Step 3: Verify EMF (optional)
  E₁ = 4.44 × 50 × 2000 × 0.0096 ≈ 4262 V? 
  Wait — this seems too high for 2300 V rating!

  Actually: For ideal transformer, V₁ ≈ E₁ (no-load condition)
  But at load, there's voltage drop. Let me recalculate.
  
  At no-load: V₁ = E₁ (approximately)
  So E₁ should be ≈ 2300 V
  
  Let me solve backwards:
  2300 = 4.44 × 50 × N₁ × Φm
  Φm = 2300 / (4.44 × 50 × 2000) = 2300 / 444000 = 0.00518 Wb
```

**Q3 (Tricky):** A transformer designed for 60 Hz is connected to 50 Hz supply at the same voltage. What happens to the flux density? What are the consequences?

**Solution:**
```
The key relationship: E = 4.44 × f × N × Φm

Rearranging: Φm = E / (4.44 × f × N)

At same voltage but lower frequency:
  Original (60 Hz): Φm₁ = E / (4.44 × 60 × N)
  New (50 Hz):     Φm₂ = E / (4.44 × 50 × N)

Taking ratio:
  Φm₂ / Φm₁ = 60/50 = 1.2

  → Flux density INCREASES by 20%!

CONSEQUENCE:
  If original B = 1.1 T (safe), new B = 1.32 T
  This exceeds typical saturation B (~1.3-1.4 T)
  
  → Core SATURATES
  → Magnetizing current increases dramatically
  → Transformer HEATS UP
  → Efficiency drops
  → May cause OVERHEATING and DAMAGE

⚠️ NEVER run a 60 Hz transformer on 50 Hz at rated voltage!
```

### FORMULA 2: Turns Ratio and Current Ratio (K = N2/N1 = V2/V1 = I1/I2)

#### Step 1 — First Principles:

```
Two windings on same iron core:

1. PRIMARY WINDING: Gets AC input voltage
2. SECONDARY WINDING: Delivers AC output voltage

MAGIC OF TRANSFORMER:
The SAME flux passes through BOTH windings (it's one shared magnetic field).

Since E ∝ N (from E = 4.44fNΦ), if same flux Φ goes through both:

E₁ ∝ N₁    and    E₂ ∝ N₂

∴ E₁/E₂ = N₁/N₂

At no-load (or light load):
V₁ ≈ E₁  and  V₂ ≈ E₂

So: V₁/V₂ ≈ N₁/N₂
```

**But there's more:**

In an IDEAL transformer (no losses):
```
Power in = Power out
V1 x I1 = V2 x I2

Rearranging:
V1/V2 = I2/I1
```

**COMBINING:**
```
K = N2/N1 = V2/V1 = I1/I2
```

Where K is called the **transformation ratio** or **turns ratio**.

**Important Convention:**
- If K > 1: Step-UP transformer (V₂ > V₁, N₂ > N₁, I₂ < I₁)
- If K < 1: Step-DOWN transformer (V₂ < V₁, N₂ < N₁, I₂ > I₁)

#### Step 2 — Real Life Anchor:

> Think of a water pipe analogy:
> - Two pipes connected (like windings on same core)
> - Same water flow (like same flux Φ)
> - One pipe is thick (low resistance), one is thin (high resistance)
> - Thick pipe = many turns (N large), thin pipe = few turns (N small)
> - Water pressure (voltage) is higher in thin pipe because same force is concentrated

> In India: Step-down transformers everywhere
> - 11 kV (high voltage, low current) → 415 V (low voltage, high current)
> - Your house gets 230 V, but the distribution line carries 11 kV
> - Why high voltage for transmission? Because P = V × I, so for same power, higher V = lower I = thinner/cheaper wires

#### Step 3 — Exam Form:

```
K = N₂/N₁ = V₂/V₁ = I₁/I₂

Also written as: a = N₁/N₂ = V₁/V₂ = I₂/I₁ (inverse convention)

⚠️ KEY: When exam says "230V/115V transformer":
   V₁/V₂ = 230/115 = 2
   This means a = 2 (primary has 2× more turns than secondary)
   I₁/I₂ = 2 → Secondary current is HALF of primary current
```

#### Step 4 — Examiner Tweaks:

| Tweak | The Trap | Counter |
|-------|----------|---------|
| 1 | Confusion between "step-up" and "step-down" | Step-UP: V₂ > V₁, so N₂ > N₁, K > 1 |
| 2 | They ask "load current 10A on secondary" — what's primary? | Use I₁ = I₂ × (V₂/V₁) or I₁ = I₂/K |
| 3 | They give kVA rating, ask for current | S = V × I → I = S/V (use appropriate V) |

#### Practice Questions:

**Q1 (Easy):** A 5 kVA, 2300V/230V transformer. Find rated currents of both windings.

**Solution:**
```
Given: S = 5 kVA = 5000 VA

Primary current (I₁):
  S = V₁ × I₁
  5000 = 2300 × I₁
  I₁ = 5000/2300 = 2.17 A

Secondary current (I₂):
  S = V₂ × I₂
  5000 = 230 × I₂
  I₂ = 5000/230 = 21.7 A

Check: I₁/I₂ = 230/2300 = 0.1
       I₂/I₁ = 2300/230 = 10 ✓
       So secondary has 10× more current ✓
```

**Q2 (Medium):** A step-down transformer has 1000 turns on primary, 100 turns on secondary. The primary voltage is 2200 V at 50 Hz.
(a) Find secondary voltage
(b) If secondary supplies 50 A to a load, find primary current
(c) What is the kVA rating of this transformer?

**Solution:**
```
(a) Turns ratio K = N₂/N₁ = 100/1000 = 0.1
   V₂ = K × V₁ = 0.1 × 2200 = 220 V

(b) For ideal transformer: V₁ × I₁ = V₂ × I₂
   I₁ = (V₂ × I₂)/V₁ = (220 × 50)/2200 = 11000/2200 = 5 A

   OR using current ratio: I₁/I₂ = V₂/V₁ = 220/2200 = 0.1
   I₁ = 0.1 × 50 = 5 A ✓

(c) kVA rating: Use either side
   Primary: S = V₁ × I₁ = 2200 × 5 = 11000 VA = 11 kVA
   Secondary: S = V₂ × I₂ = 220 × 50 = 11000 VA = 11 kVA ✓
```

### FORMULA 3: Open Circuit Test & Short Circuit Test

#### Why Do We Do These Tests?

```
Problem: Transformer has internal R and X we can't directly measure
Solution: Two simple tests that give us ALL losses and parameters
```

---

#### Summary: OC Test vs SC Test (Quick Compare)

```
Test      Why Done?              How Done?                    Side     What We Find
---------------------------------------------------------------------------------------------------------------
OC Test   Measure iron loss     Secondary OPEN               LV side  Iron loss Pi, R0, X0 (shunt branch)
           & magnetizing         Apply rated voltage to      (low     These are CONSTANT - don't change
           parameters           primary                      voltage) with load

SC Test   Measure copper loss    Secondary SHORTED            HV side  Copper loss Pcu, R01, X01, Z01
           & impedance          Apply small voltage to       (high    (series branch) - these VARY with
                               primary until rated          voltage) load (proportional to I²)

Key: OC test → shunt branch (R0, X0)    [core/magnetizing]
      SC test → series branch (R01, X01) [windings/copper]
```

---

#### Open Circuit (OC) Test

**What you do:**
```
1. Leave secondary circuit OPEN (nothing connected)
2. Apply rated voltage to PRIMARY winding
3. Measure: V1 (applied voltage), I0 (no-load current), P0 (power consumed)
```

**Test Circuit Diagram:**

![OC Test Circuit](https://circuitglobe.com/wp-content/uploads/2015/11/open-circuit-test-on-transformer.jpg)

*Source: [Circuit Globe - Open Circuit Test](https://circuitglobe.com/open-circuit-test-on-transformer.php)*

**Key Measurement Points:**
```
Instrument    What it Measures           Purpose
------------------------------------------------
Voltmeter     V1 (rated LV voltage)      Reference voltage
Ammeter       I0 (~5% rated current)    Magnetizing current
Wattmeter     P0 (iron losses)           Core losses (hysteresis + eddy)
```

**Why LV side?**
```
- LV rated voltage is low (e.g., 230V)
- Easy to apply rated voltage from variac
- HV side would need thousands of volts - dangerous!
```

**What it tells us:**
```
Measurement          What It Represents
-------------------------------------------------
I0 (~5% rated)      Current needed to magnetize core
P0                   Iron losses (hysteresis + eddy) - CONSTANT with load
From I0 and P0       Calculate R0 and X0 (shunt branch parameters)
```

**Calculation:**
```
Iron loss Pi = P0 (measured at rated voltage)

From equivalent circuit (primary side):
  Z0 = V1 / I0          (total magnetizing impedance)
  R0 = P0 / I0²         (core resistance)
  X0 = √(Z0² - R0²)     (magnetizing reactance)
```

---

#### Short Circuit (SC) Test

**What you do:**
```
1. Short the SECONDARY winding (zero resistance link)
2. Apply REDUCED voltage to PRIMARY winding
3. Increase voltage until rated current flows in windings
4. Measure: Vsc (short circuit voltage), Isc (rated current), Psc (power loss)
```

**Test Circuit Diagram:**

![SC Test Circuit](https://circuitglobe.com/wp-content/uploads/2015/11/short-circuit-test-on-transformer.jpg)

*Source: [Circuit Globe - Short Circuit Test](https://circuitglobe.com/short-circuit-test-on-transformer.php)*

**Key Measurement Points:**
```
Instrument    What it Measures           Purpose
------------------------------------------------
Voltmeter     Vsc (small ~5-15% rated)  Impedance voltage
Ammeter       Isc (rated current)       Full-load current
Wattmeter     Psc (copper losses)       Winding I²R losses
```

**Why HV side?**
```
- HV rated current is LOW (e.g., 5A vs 50A on LV)
- Easy to set up rated current with small applied voltage
- Example: For 2300V/230V, 11kVA transformer:
    Primary (HV) rated current = 11000/2300 = 4.8A  <- Easy to set!
    Secondary (LV) rated current = 11000/230 = 47.8A <- Hard to handle!
```

**What it tells us:**
```
Measurement          What It Represents
-------------------------------------------------
Psc                  Copper loss at rated current (I²R in windings)
Vsc                  Impedance voltage (voltage needed to push rated current)
From Vsc and Psc     Calculate R01, X01, Z01 (series parameters)
```

**Calculation:**
```
Z01 (total equivalent impedance, referred to primary) = Vsc / Isc
R01 (total copper resistance, referred to primary)       = Psc / Isc²
X01 (total leakage reactance, referred to primary)      = √(Z01² - R01²)
```

#### Complete OC & SC Test Summary Table

```

```

```

### FORMULA 4: Efficiency

#### Step 1 — What is Efficiency?

```
Efficiency (η) = What you GET out / What you PUT in
             = Output Power / Input Power
             = Output / (Output + Losses)
```

For a transformer, losses are:
1. **Iron/Core Losses** (constant, from OC test) — hysteresis + eddy currents
2. **Copper Losses** (variable, depend on load) — I²R in windings

#### Step 2 — Deriving the Formula:

```
Let:
  S = rated apparent power (kVA)
  x = fraction of full load (0.5 = half load, 1.0 = full load)
  cosφ = power factor of load

Output Power = x × S × cosφ
  (at half load, you get half the apparent power, but only if pf is same)

Iron loss P_i = constant (from OC test, measured in watts)
Copper loss P_cu = x² × (full-load Cu loss)
  (Copper loss ∝ current² ∝ (load)²)
  At half load: copper loss = (0.5)² × P_cu_full = 0.25 × P_cu_full

Total losses = P_i + x² × P_cu_full

Input Power = Output + Losses = xSxcosφ + P_i + x²P_cu

Efficiency η = Output / Input
             = xSxcosφ / (xSxcosφ + P_i + x²P_cu)
```

#### Step 3 — Exam Form:

```
eta = (x x S x cosφ) / (x x S x cosφ + Pi + x^2 x Pcu)
```

Where:
```
Symbol     Meaning
--------------------------
x          Fraction of full load (0 to 1)
S          Rated apparent power (kVA)
cosφ       Load power factor
Pi         Iron loss (W) - from OC test
Pcu        Full-load copper loss (W) - from SC test
```

---

#### 🔌 Understanding Apparent Power (S) and Power Factor (cosφ) — From Scratch:

**What is Apparent Power (S)?**

```
Imagine you're the electricity company. You build a 100 kVA transformer.
This means:

  The transformer can HANDLE up to 100 kVA of power flow
  regardless of HOW that power is used.

100 kVA at 415V means:
  I = S/V = 100000/415 = 241 A flowing through the windings
  This 241A heats the windings, requires copper thickness, etc.

But here's the key: The transformer doesn't care if the 100 kVA is:
  - All used as real power ( resistive loads like heaters)
  - All reactive power (inductive loads like motors)
  - A mix

The transformer's WINDINGS see 241A either way.
That's why it's called "apparent" — it LOOKS like 100 kVA is flowing,
but the actual useful (real) power might be less.
```

**Real Power (P) vs Apparent Power (S) — The Key Distinction:**

```
Real Power (P) = What actually does WORK (measured in kW)
  → Heating (heater)
  → Lighting (lamp)
  → Moving a motor's shaft

Reactive Power (Q) = What is "borrowed" and returned (measured in kVAR)
  → Creating magnetic fields in motors
  → Building up charge in capacitors
  → Necessary for AC systems but doesn't do "useful" work

Apparent Power (S) = Vector sum of P and Q
  → What the transformer/wire "sees"
  → Determines how much current actually flows

The relationship:
  S² = P² + Q²
  S (kVA) = √(P² + Q²) in consistent units
```

**What is Power Factor (cosφ)?**

```
Power Factor = cosφ = P/S = Real Power / Apparent Power

φ (phi) = phase angle between Voltage and Current

In a RESISTIVE load (pure heater):
  Voltage and Current are IN PHASE (φ = 0°)
  cos(0°) = 1.0
  P = S × 1.0 = 100 kW
  100% of power does useful work

In an INDUCTIVE load (motor):
  Current LAGS Voltage by φ (e.g., 36.9°)
  cos(36.9°) = 0.8
  P = S × 0.8 = 80 kW
  Only 80% of apparent power does useful work
  The remaining 20% (20 kVAR) circulates back and forth

In a CAPACITIVE load:
  Current LEADS Voltage
  cos(negative angle) still positive, but leading pf
```

**The Water Pipe Analogy:**

```
Imagine a water pipe carrying water to spin a turbine:

  P (Real Power) = Water that actually SPINS the turbine
  Q (Reactive Power) = Water that just sloshes back and forth
  S (Apparent Power) = Total water flowing through the pipe

The pipe size (diameter) must be big enough for TOTAL water S,
not just the water that does work P.

Same with wires and transformers:
  They must handle TOTAL current = S/V
  even if only P/kW actually does useful work.

Power Factor = how much of the flowing water actually spins the turbine
```

**In the Efficiency Formula:**

```
The formula: η = (x·S·cosφ) / (x·S·cosφ + P_i + x²·P_cu)

x·S·cosφ = x × S × cosφ = Output Real Power (kW)
  → This is what the LOAD actually USES to do work

x·S = Apparent Power at fraction load x
  → This is what the transformer must supply

cosφ = Power Factor = what FRACTION of apparent power is useful

Example: 100 kVA transformer at 80% load, pf = 0.8
  x·S·cosφ = 0.8 × 100 × 0.8 = 64 kW (actual useful output)
  x·S = 0.8 × 100 = 80 kVA (apparent power the transformer handles)
```

**Why Power Factor Matters in Efficiency:**

```
A transformer at 100 kVA, 80% load:

Case 1: pf = 1.0 (pure resistive load like heaters)
  Output = 0.8 × 100 × 1.0 = 80 kW
  This is GOOD — all apparent power is useful power

Case 2: pf = 0.6 (motor with poor pf)
  Output = 0.8 × 100 × 0.6 = 48 kW
  Same transformer, same current, but only 48kW does useful work!
  The remaining 32 kW is reactive (doesn't do work but heats wires)

The transformer losses (P_i and P_cu) depend on ACTUAL CURRENT (I),
which depends on APPARENT POWER (S), NOT real power (P).

So at low pf, you get LESS useful output for the SAME losses!
This is why power factor correction (adding capacitors) matters.
```

#### Step 4 — When is Efficiency Maximum?

```
η is maximum when: Output = Output + Losses 
                  i.e., when copper loss = iron loss

x² × P_cu = P_i
         x = √(P_i / P_cu)
```

**Key Insight:** Maximum efficiency occurs when variable copper loss equals constant iron loss.

**Real-life anchor:**
> Distribution transformers are designed for x ≈ 0.75-0.8 (75-80% load)
> Why? Because during daytime (peak hours), they run near full load
> During nighttime (light load), iron loss dominates
> The design point balances both periods

#### Step 5 — All-Day Efficiency:

```
η_all-day = Total energy output (24h) / Total energy input (24h)
           = kWh_output / kWh_input

This matters for DISTRIBUTION transformers because:
  - They load variably through the day
  - Need to consider energy, not just instant power

Example:
  Heavy load 6 hrs: 80% load, pf 0.8
  Light load 18 hrs: 20% load, pf 0.6
  P_i = 1 kW, P_cu_fl = 1.5 kW
```

#### Practice Questions:

**Q1 (Easy):** 100 kVA transformer, iron loss = 1.2 kW, full-load copper loss = 1.8 kW. Find efficiency at:
(a) Full load, pf = 0.8
(b) Half load, pf = 0.8
(c) At what load does max efficiency occur?

**Solution:**
```
(a) Full load (x = 1), pf = 0.8:
  Output = 1 × 100 × 0.8 = 80 kW
  Iron loss = 1.2 kW
  Copper loss = 1² × 1.8 = 1.8 kW
  Total losses = 3.0 kW
  Input = 80 + 3 = 83 kW
  η = 80/83 = 0.964 = 96.4%

(b) Half load (x = 0.5), pf = 0.8:
  Output = 0.5 × 100 × 0.8 = 40 kW
  Iron loss = 1.2 kW (constant)
  Copper loss = (0.5)² × 1.8 = 0.25 × 1.8 = 0.45 kW
  Total losses = 1.2 + 0.45 = 1.65 kW
  Input = 40 + 1.65 = 41.65 kW
  η = 40/41.65 = 0.960 = 96.0%

(c) Max efficiency when P_i = x² × P_cu:
  1.2 = x² × 1.8
  x² = 1.2/1.8 = 0.667
  x = √0.667 = 0.816

  So at 81.6% of full load

  Max efficiency:
  Output = 0.816 × 100 × 0.8 = 65.3 kW
  P_i = 1.2 kW, P_cu = 1.2 kW (at this load)
  Total losses = 2.4 kW
  Input = 65.3 + 2.4 = 67.7 kW
  η_max = 65.3/67.7 = 96.5%
```

**Q2 (Tricky):** A transformer has maximum efficiency of 98% at 80 kW load (pf = 0.8). Iron loss is 1.5 kW. Find the full-load copper loss and the kVA rating.

**Solution:**
```
At max efficiency: P_i = x² × P_cu

At η = 98%:
  Output = 80 kW, η = 0.98
  Input = 80/0.98 = 81.63 kW
  Total losses = 81.63 - 80 = 1.63 kW

At max η condition:
  P_i = P_cu (since x²P_cu = P_i)
  Each loss = 1.63/2 = 0.815 kW → Wait, this isn't right...

Actually at max η: P_i = x² × P_cu
At 80 kW load: x = 80/(S × 0.8) = 100/S (where S is kVA rating)

Let P_cu_fl = full-load copper loss (unknown)
At x: P_i = x² × P_cu_fl

And we know total losses = P_i + x²P_cu_fl = 2 × P_i

From η = 80/81.63 = 98.0%:
  Total losses = 1.63 kW
  So P_i = 0.815 kW (at max η condition)

Also: At max η, x = √(P_i/P_cu_fl)
And x = 80/(S × 0.8) = 100/S

So: (100/S)² = 0.815/P_cu_fl

But also at full load copper loss = P_cu_fl
And x = 100/S at full load (x=1 when S=100 kVA, but here we're at 80 kW load)

Actually:
  Output = 80 kW at some x
  If S was 100 kVA at pf 0.8 → full load output = 80 kW
  So this IS full load condition!

Wait: 100 kVA × 0.8 = 80 kW
  So this transformer IS 100 kVA rated
  And x = 1 (full load)

So: At x=1, P_i = P_cu for max η? No, max η is at x where x²P_cu = P_i
  But here we're told max η is at 80 kW output
  At pf 0.8, S = 100 kVA means full load = 100 kVA × 0.8 = 80 kW

So max η occurs at x = 1 (full load):
  P_i = 1² × P_cu_fl
  P_i = P_cu_fl

And P_i = P_cu_fl = half of total losses = 0.815 kW = 815 W
```

### FORMULA 5: Voltage Regulation

#### Step 1 — What is Voltage Regulation?

```
When you connect a LOAD to the transformer secondary:
  - Current flows through the windings
  - Windings have resistance (R) and reactance (X)
  - This causes a VOLTAGE DROP

No-load voltage (V_nl) > Full-load voltage (V_fl)

Voltage Regulation = how much voltage drops under load

%Reg = (V_nl - V_fl) / V_fl × 100
```

**Real-life anchor:**
> When you turn on a heavy motor, your lights might dim momentarily. This is voltage drop due to current flowing through the distribution transformer's internal impedance. The problem gets worse the heavier the load and the lower the power factor.

#### Step 2 — Deriving the Regulation Formula:

```
Equivalent circuit (referred to secondary side):

  V₁' ──┬── R_eq ──┬── X_eq ──┬── V₂ (load)
        │          │          │
        └──────────┴──────────┘

At no load: V₂ = E₂ (induced EMF)
At full load: V₂ = E₂ - I₂(R_eq cosφ + jX_eq sinφ)
             = E₂ - I₂(R_eq cosφ ± jX_eq sinφ)

The +/- depends on power factor:
  Lagging pf: current lags voltage -> DROP is positive (voltage sag)
  Leading pf: current leads voltage -> voltage can ACTUALLY RISE

Regulation = (E2 - V2) / V2 x 100
           = I2(R_eq x cosφ +/- X_eq x sinφ) / V2 x 100
```

**Sign convention:**
```
Power Factor           Sign    Effect
-----------------------------------------
Lagging (inductive)    +IX     Voltage DROPS (positive regulation)
Unity                  +IX     Voltage drops (small)
Leading (capacitive)   -IX     Voltage can RISE (negative regulation possible!)
```

#### Step 3 — Exam Form:

```
%Reg = I(R01 x cosφ +/- X01 x sinφ) / V1 x 100
```

Where R01 and X01 are the equivalent parameters referred to the primary side (or secondary, depending on which side you're calculating from).

**Simplified (ignoring R):**
```
%Reg = I x X01 x sinφ / V1 x 100
```

**Even simpler (lagging pf):**
```
%Reg = Vdrop / V x 100 = IX x sinφ / V x 100
```

**Q1 (Easy):** A transformer has per-unit impedance of 0.05 pu. Find voltage regulation at 0.8 pf lagging.

**Solution:**
```
Per-unit system:
  Z_pu = 0.05
  At rated load current I_pu = 1.0

  Voltage drop in pu = I_pu × Z_pu × sinφ (lagging)
                     = 1.0 × 0.05 × sin(arccos(0.8))
                     = 0.05 × 0.6 = 0.03 pu

  %Reg = 0.03 × 100 = 3%

Or using the full formula:
  %Reg = (I × R cosφ + I × X sinφ)/V × 100
  With Z = 0.05, if R ≈ 0 (typical for large transformer)
  Then X ≈ Z = 0.05

  %Reg = I × X × sinφ × 100
       = 1 × 0.05 × 0.6 × 100 = 3%
```

**Q2 (Medium):** A 100 kVA, 2300V/230V transformer has equivalent resistance of 0.02 pu and reactance of 0.05 pu. Find regulation at:
(a) 0.8 pf lagging
(b) 0.8 pf leading
(c) Unity pf

**Solution:**
```
Given:
  R_eq = 0.02 pu, X_eq = 0.05 pu
  cosφ = 0.8, sinφ = 0.6

(a) Lagging pf:
  %Reg = (R cosφ + X sinφ) × 100
       = (0.02 × 0.8 + 0.05 × 0.6) × 100
       = (0.016 + 0.030) × 100
       = 0.046 × 100 = 4.6%

(b) Leading pf:
  %Reg = (R cosφ - X sinφ) × 100
       = (0.02 × 0.8 - 0.05 × 0.6) × 100
       = (0.016 - 0.030) × 100
       = -0.014 × 100 = -1.4%

  Negative regulation! Voltage actually RISES at leading pf.

(c) Unity pf (cosφ = 1, sinφ = 0):
  %Reg = (R × 1 + X × 0) × 100
       = 0.02 × 100 = 2%

Observation: Lagging worst, leading best (or even negative)
```

**Q7 (APGENCO 2020):** Answer briefly:
(a) Why is transformer rating in kVA and not kW?
(b) What happens if a transformer designed for 50Hz is operated at 60Hz with same voltage?
(c) Why does an autotransformer have higher efficiency than a two-winding transformer?

**Solution:**
```
(a) Transformer has two main losses:
    - Core losses (iron loss) depend on voltage (P ∝ V × I_cosφ, fixed by V)
    - Copper losses depend on current (P ∝ I²R, depends on load)
    Since these losses depend on different parameters (V and I separately),
    and apparent power S = V × I determines heating,
    the rating must be in kVA (apparent power), not kW (real power).

(b) For same voltage but higher frequency:
    E = 4.44 × f × N × Φm, so Φm = E/(4.44 × f × N)
    At 60Hz vs 50Hz: Φm decreases by factor 50/60 = 5/6
    Since iron loss ∝ f × B² and B ∝ Φm/A, net effect is:
    - Hysteresis loss ∝ f × B² → increases (60/50 = 1.2)
    - Eddy current loss ∝ f² × B² → increases significantly
    Result: More losses, more heating, transformer may overheat.

(c) Autotransformer has higher efficiency because:
    - The primary and secondary share a common winding
    - For same power transfer, only part of the power flows through resistance
    - Copper loss ∝ I²R, and since current in shared winding is DIFFERENCE
      of primary and secondary currents (much smaller), losses are lower
    - Savings = (1 - 1/a) where a = transformation ratio
    - For a = 2, savings = 50%; for a = 10, savings = 90%
```

### 📊 Waveform Parameters in Transformers — How APGENCO/TRANSCO Asks These

#### 🎯 Why This Matters in Transformers

The **"4.44"** in the transformer EMF equation comes directly from waveform parameters:
$$E = 4.44 \times f \times N \times \Phi_m$$

```
How 4.44 connects to form factor and peak factor:

  Form Factor (FF)     = RMS / Average = (a/√2) / (2a/π) = π/(2√2) = 1.11
  Peak Factor (Crest)  = Peak / RMS = 2 = 1.414
  4.44 = FF x 4 = 1.11 x 4 = 4.44

Quick Derivation (Exam Version):
  Step 1: Faraday's Law: e = N x dPhi/dt
  Step 2: For sinusoidal flux Phi = Phip x sin(wt):
          dPhi/dt = Phip x w x cos(wt)
  Step 3: RMS of e = N x w x Phip / sqrt(2)
  Step 4: But w = 2pi x f, so:
          E_rms = N x 2pi x f x Phip / sqrt(2)
                = (2pi/sqrt(2)) x f x N x Phip
                = pi x sqrt(2) x f x N x Phip
                = 4.44 x f x N x Phip
```

📌 **Memory Anchor:**
- 4.44 = 4 x Form Factor (1.11)
- 4.44 = pi x sqrt(2)
- **Sine wave FF = 1.11 is the reference** — all other waveforms compared to this

---

#### 📊 Complete Waveform Reference Table

| Wave Type | RMS | ARV (Average) | Form Factor |
|---|---|---|---|
| **Sine Wave** | a/√2 = 0.707a | 2a/π = 0.637a | **1.11** |
| **Half-Wave Rectified** | a/2 = 0.5a | a/π = 0.318a | 1.57 |
| **Full-Wave Rectified** | a/√2 = 0.707a | 2a/π = 0.637a | **1.11** |
| **Square Wave** | a | a | 1.0 |
| **Pulse Wave (D = duty cycle)** | a × √D | a × D | 1/√D |
| **Triangle Wave** | a/√3 = 0.577a | a/2 = 0.5a | 1.15 |

**Key:** `a` = peak value, `D` = duty cycle = τ/T, `ω = 2πf`

#### 🎯 What Each Parameter Means

**RMS (Root Mean Square) — "Heating Value"**
> If you send DC current of value "RMS" through a resistor, it produces the **SAME HEAT** as the AC waveform.
> - Your 230V AC mains has RMS = 230V, Peak voltage = 230 × √2 ≈ 325V
> - Formula: RMS = √[ (1/T) × ∫₀ᵀ f(t)² dt ]

**Average (ARV) — "Average Height"**
> The mathematical average of all values (ignoring +/- sign).
> - Used in: Rectifier circuits, DC meter calibration
> - Average of pure AC sine = 0 (positive cancels negative) → we use |f(t)| (absolute values)
> - Formula: ARV = (1/T) × ∫₀ᵀ |f(t)| dt

**Form Factor (FF) — "Wave Shape Indicator"**
> FF = RMS / ARV
> - FF = 1.0 → Perfect flat DC (square wave)
> - FF = 1.11 → Standard sine wave (**REFERENCE**)
> - FF > 1.5 → Very peaky (inefficient for heating)

## FORMULA 1: Star (Y) and Delta (Δ) Connections — Line vs Phase Values

### STEP 1 — First Principles:

**What even is "three phase"?**

Single phase = 1 wire, voltage goes up and down as a sine wave
Three phase = 3 wires, each carrying the same sine wave but **120° apart** from each other

**Why 120° apart?**
```
Imagine 3 people pushing a turnstile:
  Person 1 pushes at 0° position
  Person 2 pushes at 120° position
  Person 3 pushes at 240° position

Result: One person is always pushing at peak, others at partial force
        → Even, continuous rotation (smoother than one person alone!)

Same with 3-phase power:
  - More constant power delivery (no pulsing like single phase)
  - More efficient transmission (less conductor material for same power)
  - All Indian power systems use 3-phase for this reason
```

**How is a 3-phase transformer built?**

It's essentially **3 single-phase transformers sharing one iron core:**

```
Visual — 3-limb core:
           ┌─────────────────────────┐
           │    THREE-PHASE          │
           │      IRON CORE          │
           │   (3 limbs, one per    │
           │    phase)              │
           └─────────────────────────┘
                │    │    │
               Phase Phase Phase
               A     B     C
               │     │     │
             Windings on each limb
```

### STEP 2 — Real Life Anchor:

**Your house connection in India:**
```
The distribution transformer on the pole near your house is 3-phase.
It supplies:
  - 240V between any ONE phase and neutral (your home single-phase)
  - 415V between ANY TWO phases (for factories, 3-phase motors)

Why 415V? → Indian standard is 415V = √3 × 240V ✓

A factory gets 3-phase 415V to run heavy motors.
Your home gets single-phase 240V (one of the three phases).
```

**The Y connection gives you a neutral point (ground reference):**
```
Each house in a locality gets ONE phase + neutral.
The neutral is grounded at the transformer's star point.
```

### STEP 3 — Exam Form:

**STAR (Y) Connection:**
```
  KEY RELATIONSHIPS:
  V_L = √3 × V_Ph        (Line Voltage = √3 × Phase Voltage)
  I_L = I_Ph              (Line Current = Phase Current)

  Example: If V_Ph = 240V → V_L = 240 × 1.732 = 415V ✓
```

**DELTA (Δ) Connection:**
```
  KEY RELATIONSHIPS:
  V_L = V_Ph              (Line Voltage = Phase Voltage)
  I_L = √3 × I_Ph        (Line Current = √3 × Phase Current)

  Example: If I_Ph = 100A → I_L = 100 × 1.732 = 173A ✓
```

**Summary Table — MUST MEMORIZE:**

| Connection | V_L vs V_Ph | I_L vs I_Ph |
|------------|-------------|-------------|
| **Star (Y)** | V_L = **√3** × V_Ph | I_L = I_Ph |
| **Delta (Δ)** | V_L = V_Ph | I_L = **√3** × I_Ph |

**Power in 3-Phase (both Y and Δ use the same formula!):**
$$P = \sqrt{3} \times V_L \times I_L \times \cos\phi$$
$$Q = \sqrt{3} \times V_L \times I_L \times \sin\phi$$
$$S = \sqrt{3} \times V_L \times I_L$$

| 4 | "Δ: I_L > I_Ph or I_Ph > I_L?" | I_L is always √3 × larger |

## FORMULA 2: Vector Groups and Phase Shift

### STEP 1 — First Principles:

**Why does phase shift happen?**

In single-phase transformer: primary and secondary voltages are **in phase**.

In 3-phase transformer, when primary is Y and secondary is Δ (or vice versa), voltages are **shifted by 30°**.

**The Clock Analogy:**
```
Primary voltage as minute hand at 12 o'clock (0°):

If secondary points to 1 o'clock → +30° shift
If secondary points to 11 o'clock → -30° shift (actually +330°, or lags by 30°)
```

**Why does this happen geometrically?**
```
Star connection: Voltage measured from phase to neutral
Delta connection: Voltage measured across the winding

The reference point changes when converting Y ↔ Δ.
This creates a 30° shift.
```

### STEP 2 — Real Life Anchor:

**Indian Power System — Common Vector Groups:**

| Connection | Phase Shift | Use |
|------------|-------------|-----|
| **Dy11** | LV lags HV by 30° | Most common in India |
| **Yd11** | LV lags HV by 30° | Very common |
| **Dy1** | LV leads HV by 30° | Less common |
| **Yy0** | 0° (in phase) | Rare |

**On a transformer nameplate "Dyn11":**
```
D = HV side Delta
y = LV side Star
n = neutral brought out
11 = LV lags HV by 30°
```

### STEP 3 — Exam Form:

**Vector Group Notation:**
```
First letter = HV winding (Y, D, or Z)
Second letter = LV winding (y, d, or z)
Optional third letter = neutral (N or n)
Number = Phase displacement in clock hours (0 to 11)

Dy11 means:
  D = HV Delta, y = LV Star, 11 = LV lags HV by 30°
```

**Phase Shift by Number:**

| Number | Degrees | Meaning |
|--------|---------|---------|
| 0 | 0° | In phase |
| 1 | -30° | LV leads |
| 11 | +30° | LV lags |
| 6 | 180° | Opposite |

### STEP 4 — Examiner Tweaks:

| Tweak | The Trap | Counter |
|-------|----------|---------|
| 1 | "A = Dy11, B = Dy1 — parallel?" | 30° + 30° = 60° diff → NO |
| 2 | "Yy0 has what shift?" | 0° shift |
| 3 | "Dy11 secondary angle if HV at 0°?" | -30° (lags) |
| 4 | "Which leads — Y or Δ?" | Y voltage leads Δ by 30° in Dy11 |

### STEP 5 — Practice Questions:

**Q1 (APPSC 2019):** Two transformers A (Dy11) and B (Dy1) to parallel. Can they?

**Solution:**
```
NO!

Dy11: LV lags HV by 30°
Dy1:  LV leads HV by 30°

Difference: 30° + 30° = 60°

Even with identical voltages, this 60° phase difference creates
massive circulating current → would trip breakers or destroy TX.

Vector groups MUST match for parallel operation.
```

## FORMULA 3: Parallel Operation — The 5 Conditions

### STEP 1 — First Principles:

**Why parallel transformers?**
```
When one transformer can't handle the load:

        Source ──┬──[TX A]──┬── Load
                 │          │
                 └──[TX B]──┘

Both share the load. Common in Indian substations.
```

**Why all 5 conditions matter:**
```
Each condition prevents a specific failure mode:
1. Wrong polarity → voltages cancel instead of add
2. Wrong phase sequence → R connected to Y (120° apart)
3. Wrong voltage ratio → circulating current at no-load
4. Wrong Z% → unequal load sharing
5. Wrong vector group → phase difference = huge current
```

### STEP 2 — Real Life Anchor:

**Indian Substation Example:**
```
132/33 kV substation with two 50 MVA transformers:
  - Both Yd11 (standard in AP)
  - Both Z% ~ 10-12%
  - Both tested for polarity before commissioning

If vector groups mismatched (Yd11 with Yy0):
  - 30° phase difference
  - At 33 kV, circulating current = thousands of amps
  - Would trip breakers or cause explosion within seconds
```

### STEP 3 — Exam Form:

```
================================================================
          PARALLEL OPERATION -- ALL 5 CONDITIONS REQUIRED
================================================================
1. SAME POLARITY
   Why: Wrong polarity = voltages subtract

2. SAME PHASE SEQUENCE
   Why: R connected to Y = 120 deg apart = short circuit

3. SAME VOLTAGE RATIO (+/- 5%)
   Why: Different ratios = circulating current at no-load

4. SAME Z% (+/- 10%)
   Why: Load shared inversely proportional to Z%

5. SAME VECTOR GROUP (CRITICAL!)
   Why: Even 30 deg difference = massive circulating current
================================================================
```

### STEP 4 — Examiner Tweaks:

| Tweak | The Trap | Counter |
|-------|----------|---------|
| 1 | "Yy0 parallel with Yd11?" | 0° vs 30° → NO |
| 2 | "11kV/415V parallel with 11.5kV/415V?" | Diff = 4.5% → borderline |
| 3 | "Z% 6% parallel with 15%?" | Diff > 10% → unequal sharing |
| 4 | "Both Yd11 — ready to parallel?" | Need all 5 conditions |
| 5 | "What if vector groups match but polarity wrong?" | Still fails! |

### STEP 4B — FAILURE CALCULATIONS: What Happens Mathematically

**The General Formula for Circulating Current:**

When a condition fails, the parallel is effectively a **voltage source (ΔV) driving current through the loop impedance (Z₁ + Z₂)**:

$$I_{circ} = \frac{\Delta V}{Z_1 + Z_2}$$

Each failure mode has a different $\Delta V$:

| Failure Mode | What Happens | $\Delta V$ Formula | $\Delta V$ Example (415V sys) | Severity |
|---|---|---|---|---|
| **Polarity reversed** | Secondary wired backwards → voltages oppose | $\Delta V = 2 \times V_{Ph}$ | $2 \times 240 = 480$ V | **△ Extreme** |
| **Phase sequence wrong** | Y↔B swapped → phases 120° apart | $\Delta V = \sqrt{3} \times V_{Ph}$ | $1.732 \times 240 = 415$ V | **△ Extreme** |
| **Turns ratio mismatch** (±5%) | Voltage slightly different | $\Delta V = \text{diff \%} \times V_{Ph}$ | $0.05 \times 240 = 12$ V | Moderate |
| **Vector group mismatch** (Yd11 vs Yd1) | 60° phase difference | $\Delta V = V_{Ph}$ (for 60°) | $240$ V | **△ Extreme** |
| **%Z mismatch** | Load sharing imbalance | NO circulating current — load divides inversely with Z% | — | Overloads low-Z unit |

**Key Calculation Steps for Any Failure:**

```
Step 1: Find the voltage difference (ΔV) based on failure mode
Step 2: Find each transformer's impedance in ohms:
           Z_base = V² / S (on the side being paralleled)
           Z_TX = Z_pu × Z_base
Step 3: Loop impedance = Z_T1 + Z_T2  (both in series in the loop)
Step 4: I_circ = ΔV / Z_loop
Step 5: Compare to rated current: I_rated = S / V (single-phase)
                                         = S / (√3 × V_L) (3-phase)
```

### STEP 5 — Practice Questions (With Full Calculated Solutions)

**Q1 (APPSC 2017 - Very Common):** State the 5 conditions for parallel operation of 3-phase transformers. Why is vector group critical?

**Solution:**
```
1. Same polarity
2. Same phase sequence  
3. Same voltage ratio (±5%)
4. Same Z% (±10%)
5. Same vector group (CRITICAL!)

Why vector group is critical:
  - Different vector groups = different phase displacement
  - Example: Yd11 (+30°) vs Yd1 (-30°) = 60° difference
  - Even with perfect voltage match, this causes circulating 
    current of thousands of amps in large transformers
  - Would trip breakers, overheat windings, or cause explosion

Conclusion: Vector group must match EXACTLY. Other conditions
can have small tolerances, but vector group must be identical.
```

**Q2 (APGENCO 2019):** Two TXs rated 5 MVA (Z%=6%) and 10 MVA (Z%=8%), both 11kV/433V, Yd11. Can they parallel?

**Solution:**
```
Vector group: Both Yd11 → MATCH ✓
Voltage ratio: Both 11kV/433V → MATCH ✓
Z% difference: |8-6| / ((8+6)/2) × 100% = 28.6% → >10%!

Problem: Z% differs significantly → unequal load sharing
  TX A (6%) takes more load than TX B (8%)
  TX A will be overloaded before TX B is fully loaded

Verdict: Technically possible but not recommended without derating.
Small Z% tolerance OK, large MVA mismatch needs protection coordination.
```

**Q3 (MUST SOLVE — Polarity Reversal Calculation):** Two identical 500 kVA, 11kV/415V single-phase transformers are paralleled on both primary and secondary. Each has $Z_{pu} = 0.05$. The second transformer has its **secondary polarity reversed**. Calculate the circulating current in the secondary loop when unloaded.

**Solution:**
```
GIVEN:
  S = 500 kVA = 500,000 VA
  V₂ = 415 V (secondary rated)
  Z_pu = 0.05 per transformer

STEP 1 — Voltage difference due to polarity reversal:
  With reversed polarity, T1's a1(+) connects to T2's a1(-)
  ΔV = V_T1 - (-V_T2) = 415 - (-415) = 830 V
  [They oppose each other → double voltage around the loop]

STEP 2 — Find each transformer's impedance in ohms:
  Z_base (on 415V side) = V² / S = 415² / 500,000
                        = 172,225 / 500,000 = 0.344 Ω
  Each TX: Z = Z_pu × Z_base = 0.05 × 0.344 = 0.0172 Ω

STEP 3 — Loop impedance (both in series):
  Z_loop = Z_T1 + Z_T2 = 0.0172 + 0.0172 = 0.0344 Ω

STEP 4 — Circulating current:
  I_circ = ΔV / Z_loop = 830 / 0.0344 = 24,128 A

STEP 5 — Compare to rated current:
  I_rated (secondary) = S / V = 500,000 / 415 = 1,205 A
  Ratio = 24,128 / 1,205 = 20.0× rated current

CONCLUSION: 20× rated current flows continuously.
  → Protection trips immediately or transformer burns within seconds.
  → THIS IS WHY POLARITY MUST BE VERIFIED BEFORE PARALLELING.
```

**Q4 (MUST SOLVE — Phase Sequence Mismatch):** Two identical 2 MVA, 11kV/415V, Dyn11 transformers are to be paralleled. One has **Y and B swapped** on its primary (RBY sequence instead of RYB). Each has $Z_{pu} = 0.06$. Calculate the circulating current.

**Solution:**
```
GIVEN:
  S = 2 MVA = 2,000,000 VA (3-phase)
  V_L = 415 V (secondary line voltage)
  Z_pu = 0.06 per transformer
  Connection: Dyn11 (Delta primary, Star secondary)

STEP 1 — What happens with RBY vs RYB?
  T1 (RYB):   T1.R = 0°, T1.Y = -120°, T1.B = +120°
  T2 (RBY):   T2.Y terminal carries what should be B-phase (+120°)
              T2.B terminal carries what should be Y-phase (-120°)
  
  Compare T1.Y (at -120°) vs T2.Y (at +120°):
  Phase difference = 120° - (-120°) = 240° = -120° (effective angle)
  
  Voltage difference magnitude between these two Y-phase terminals:
  |ΔV| = √[V_Ph² + V_Ph² - 2·V_Ph²·cos(120°)]
       = V_Ph × √3

STEP 2 — Find phase voltage:
  Star secondary: V_Ph = V_L / √3 = 415 / 1.732 = 239.6 V
  |ΔV| = 239.6 × 1.732 = 415 V  [FULL LINE VOLTAGE!]

STEP 3 — Find each transformer's impedance in ohms:
  Z_base (on 415V side, 3-phase) = V_L² / S = 415² / 2,000,000
                                 = 172,225 / 2,000,000 = 0.0861 Ω
  Each TX (per-phase): Z = Z_pu × Z_base = 0.06 × 0.0861 = 0.00517 Ω

STEP 4 — Loop impedance:
  Z_loop = Z_T1 + Z_T2 = 0.00517 + 0.00517 = 0.01033 Ω

STEP 5 — Circulating current through Y-phase pair:
  I_circ = ΔV / Z_loop = 415 / 0.01033 = 40,174 A

STEP 6 — Compare to rated current:
  I_rated (line current) = S / (√3 × V_L) = 2,000,000 / (1.732 × 415)
                         = 2,000,000 / 718.8 = 2,782 A
  Ratio = 40,174 / 2,782 = 14.4× rated current

CONCLUSION: 14.4× rated current flows through the mismatched phase pair.
  Same problem on all three phase pairs → instantaneous destruction.
```

**Q5 (Vector Group Mismatch Calculation):** Two 1 MVA, 11kV/433V transformers — one **Yd11** and one **Yd1** — have identical ratings and Z_pu = 0.055 each. If mistakenly paralleled, calculate the circulating current.

**Solution:**
```
GIVEN:
  S = 1 MVA = 1,000,000 VA (3-phase)
  V_L = 433 V (secondary)
  T1: Yd11 (LV lags HV by 30° → +30° shift)
  T2: Yd1  (LV leads HV by 30° → -30° shift)
  Z_pu = 0.055 per transformer

STEP 1 — Phase difference:
  Yd11: Secondary voltage = +30° from primary reference
  Yd1:  Secondary voltage = -30° from primary reference
  Angular difference = 30° - (-30°) = 60°

STEP 2 — Voltage difference:
  For two vectors of magnitude V_Ph separated by 60°:
  |ΔV| = √[V_Ph² + V_Ph² - 2·V_Ph²·cos(60°)]
       = √[2V_Ph²(1 - 0.5)] = √[V_Ph²] = V_Ph

  V_Ph (Star secondary) = 433 / √3 = 250 V
  |ΔV| = 250 V  [full phase voltage difference!]

STEP 3 — Impedance in ohms:
  Z_base = (433)² / 1,000,000 = 187,489 / 1,000,000 = 0.1875 Ω
  Each TX (per-phase): Z = 0.055 × 0.1875 = 0.0103 Ω
  Z_loop = 0.0103 + 0.0103 = 0.0206 Ω

STEP 4 — Circulating current:
  I_circ = 250 / 0.0206 = 12,136 A

STEP 5 — Compare to rated:
  I_rated = 1,000,000 / (√3 × 433) = 1,000,000 / 750 = 1,333 A
  Ratio = 12,136 / 1,333 = 9.1× rated current

CONCLUSION: 9× rated current. Slightly less than polarity failure
(which is 2×V_Ph = 500V difference), but still destructive.

**Vector group matching is NON-NEGOTIABLE for paralleling.**
```

**Q6 (Combined Failure — Polarity + Phase Sequence):** Three 100 kVA single-phase transformers form a 3-phase Δ/Y bank (11kV/415V). One transformer (B-phase) has its **secondary polarity reversed**. This bank is paralleled with an identical correctly-connected bank. Each TX has Z_pu = 0.04. Find:
(a) Voltage difference on B-phase
(b) Circulating current in B-phase
(c) Current in the neutral wire

**Solution:**
```
GIVEN:
  S = 100 kVA per phase = 300 kVA bank rating
  V₂(phase) = 415/√3 = 239.6 V (Star secondary)
  Z_pu = 0.04 per single-phase TX

STEP 1(a) — Per-transformer impedance:
  Z_base (per phase) = V_Ph² / S = 239.6² / 100,000
                     = 57,408 / 100,000 = 0.574 Ω
  Each TX: Z = 0.04 × 0.574 = 0.02296 Ω

STEP 1(b) — Voltage difference on B-phase:
  Bank 1 (correct): B-phase = V_Ph ∠ +120°
  Bank 2 (reversed): B-phase polarity flipped:
    -V_Ph ∠ +120° = V_Ph ∠ (120° - 180°) = V_Ph ∠ -60°
  
  Angular difference = 120° - (-60°) = 180°
  |ΔV_B| = √[V_Ph² + V_Ph² - 2·V_Ph²·cos(180°)]
          = √[2V_Ph²(1 - (-1))] = √[4V_Ph²] = 2 × V_Ph
          = 2 × 239.6 = 479.2 V

STEP 2 — Circulating current in B-phase:
  I_circ,B = 479.2 / (2 × 0.02296) = 479.2 / 0.04592 = 10,436 A

STEP 3 — Neutral current:
  R-phase and Y-phase: Correct polarity, same phase → ΔV = 0 → no current
  Only B-phase has circulating current → all returns via neutral
  I_N = I_circ,B = 10,436 A
  
  I_rated per TX = 100,000 / 239.6 = 417 A
  Ratio = 10,436 / 417 = 25.0× rated!

CONCLUSION: B-phase carries 25× rated current. Neutral carries 10,436 A.
  The neutral wire vaporizes instantly. B-phase transformer burns.
```

## FORMULA 4: Auto-Transformer

### STEP 1 — First Principles:

**What is an auto-transformer?**

A transformer with **ONE continuous winding** serving as both primary and secondary (part is shared).

```
NORMAL TRANSFORMER:         AUTO-TRANSFORMER:
  Primary   Secondary         Single winding:
  ──────    ────────         ──────────────────────
      │        │                  │
      │        │                  │
  Electrically           Electrically
  ISOLATED              CONNECTED!
```

**How it works:**
```
         N₁ turns (entire)
    ─────────────────────────
    │                       │
    │  N₂ turns (section    │
    │  = secondary)        │
────┴──┤         ├──────────── V₂ (output)
        │         │
        └─────────┘
          ↑
        Tap point

V₂ = (N₂/N₁) × V₁ = V₁/a
```

### STEP 2 — Real Life Anchor:

**Auto-transformers are used for:**

```
1. Motor starting (reduced voltage):
   - Apply 70% voltage → starting current 49%
   - Starting torque reduced to 49%

2. Voltage regulators (tap changers):
   - Small adjustments to keep 240V steady
   - Brown transformers on poles

3. Testing labs (Variac):
   - Dial to get 0-270V from 230V input

4. ⚠️ NEVER for household supply:
   - NO ISOLATION = DANGEROUS if primary is high voltage
   - Your 11kV/240V house TX is always normal (isolated)
```

### STEP 3 — Exam Form:

**Key Relationships:**
```
a = N₁/N₂ = V₁/V₂  (transformation ratio, a > 1 for step-down)

V₂ = V₁ × (N₂/N₁) = V₁/a

I_common = I₂ - I₁ (at the tap point, by KCL)
```

**Material Saving:**
```
Saving = (1 - 1/a) × 100%

| Ratio | a | Saving |
|-------|---|--------|
| 2:1 (230/115V) | 2 | 50% |
| 10:1 (2300/230V) | 10 | 90% |
```

**⚠️ KEY: Savings biggest when a ≈ 1 (small voltage change)**

### STEP 4 — Examiner Tweaks:

| Tweak | The Trap | Counter |
|-------|----------|---------|
| 1 | "Why cheaper?" | Only one winding, shared portion |
| 2 | "Household use?" | NO — no isolation = dangerous |
| 3 | "Current in common portion?" | I_tap = I₂ - I₁ |
| 4 | "a = 2 means?" | Step-down, 50% saving |
| 5 | "When is saving largest?" | When a is close to 1 |

### STEP 5 — Practice Questions:

**Q1 (APTRANSCO 2018):** Auto-transformer 460V/230V. Calculate ratio and copper saving.

**Solution:**
```
Given: V₁ = 460V, V₂ = 230V

Step 1: a = V₁/V₂ = 460/230 = 2

Step 2: Saving = (1 - 1/a) × 100%
       = (1 - 1/2) × 100% = 50%
```

**Q2 (APPSC 2019):** Why NOT use auto-transformer for house supply?

**Solution:**
```
SAFETY: NO ISOLATION between primary and secondary!

Normal transformer: Primary (11 kV) and secondary (240V) are
MAGNETICALLY coupled but ELECTRICALLY ISOLATED.

Auto-transformer: Primary and secondary are the SAME WINDING,
ELECTRICALLY CONNECTED.

If primary is 11 kV and secondary is 5 kV tap:
  Touching the 5 kV output means touching PART OF THE 11 KV CIRCUIT.
  The human body completes the circuit to the 11 kV source.

Household use = people can touch the output = UNACCEPTABLE RISK.
```

**Q3 (APGENCO 2020):** 100 kVA load fed from 1000V/500V auto-transformer. Find winding VA.

**Solution:**
```
Given: V₁ = 1000V, V₂ = 500V, S = 100 kVA

Step 1: a = 1000/500 = 2

Step 2: I₁ = S/V₁ = 100000/1000 = 100A
        I₂ = S/V₂ = 100000/500 = 200A

Step 3: Winding carries (inductive portion):
        = V₁ × I₁ = 1000 × 100 = 100 kVA

But actual power transferred:
        = 100 kVA (50 kVA conductive + 50 kVA inductive)

The winding only handles 50 kVA magnetically!
That's why auto-transformers are smaller.
```

   -> Savings = (1 - 1/a) x 100%  where a = V1/V2
   -> WARNING: Cannot use where isolation is needed!
```

## FORMULA 1: EMF Equation in DC Machines

### STEP 1 — First Principles:

**How does a DC machine generate voltage?**

A DC machine is essentially a **reversed motor** — instead of using electricity to make motion, it uses motion to generate electricity.

```
Basic principle:
  1. A conductor (wire) moves through a magnetic field
  2. This "cuts" magnetic flux lines
  3. Faraday's Law: A changing magnetic flux through a coil induces EMF
  4. The EMF is collected via commutator and brushes

Physical setup:
  ┌──────────────────────────────────────┐
  │          ARMATURE (rotor)            │
  │   ┌────────────────────────────┐    │
  │   │  Conductors on surface    │    │
  │   │  (carrying current out)   │    │
  │   └────────────────────────────┘    │
  │                                      │
  │   ←── Rotation (mechanical input)  │
  │                                      │
  │  N    S    N    S    N    S        │
  │  ↑ Poles on stator (field) ↑        │
  └──────────────────────────────────────┘
              │
              │ Commutator + Brushes
              ▼
         DC Output
```

**The EMF Equation — Step by Step:**

```
In one rotation of the armature:
  Each conductor passes through ALL poles
  Number of poles = P
  Each conductor cuts flux from N pole and S pole

Flux cut per conductor per revolution = P × Φ
  (Φ = flux per pole)

If N revolutions per minute:
  Number of revolutions per second = N/60

Flux cut per second by ONE conductor = (P × Φ) × (N/60)

But there are Z conductors on the armature...
  Total flux cut per second = (P × Φ × N × Z) / 60

According to Faraday's Law, this equals the generated EMF...

BUT: The armature is divided into A parallel paths
  (A = 2 for wave winding, A = P for lap winding)

So the EMF per parallel path = total flux cut / A

E = (P × Φ × N × Z) / (60 × A)
```

### STEP 2 — Real Life Anchor:

**DC machines in India:**

```
DC generators were used in early power systems (pre-1950s).
Today, DC motors are still important in:

1. DC Crane drives (steel plants, ports)
   → Precise speed control needed
   → 220V DC motors with Ward-Leonard control

2. DC traction (old electric trains, metros)
   → Delhi Metro uses DC 750V third rail
   → Most electric locomotives are DC series motors

3. Electroplating and battery charging
   → Need smooth DC output
   → DC generator with regulator

4. Emergency backup generators
   → Some hospitals have DC emergency lighting systems

5. DC testing labs
   → Variable voltage DC for testing

The EMF equation tells you:
  - How fast the generator must rotate (N)
  - How many conductors (Z)
  - How much flux per pole (Φ)
  - How many poles (P)
  to get the desired voltage
```

### STEP 3 — Exam Form:

$$E_g = \frac{P \cdot \Phi \cdot N \cdot Z}{60 \cdot A} \text{ volts}$$

Where:
| Symbol | Name | Typical Value | Unit |
|--------|------|---------------|------|
| P | Number of poles | 4, 6, 8 | — |
| Φ | Flux per pole | 0.02-0.05 | Weber (Wb) |
| N | Speed | 1500, 1800, 3000 | RPM |
| Z | Total armature conductors | 100-1000 | — |
| A | Parallel paths | 2 (wave) or P (lap) | — |

**Special Cases:**

```
Wave winding:  A = 2 (always, regardless of poles)
Lap winding:   A = P (number of poles)

For a 4-pole, wave-wound machine: A = 2
For a 4-pole, lap-wound machine: A = 4
```

## FORMULA 2: Torque Equation in DC Machines

### STEP 1 — First Principles:

**What is torque in a DC machine?**

Torque is the **turning force** produced by the machine.

```
How torque is produced:
  1. Current flows through armature conductors
  2. Each conductor in a magnetic field experiences force F = BIL
  3. Force on each conductor is perpendicular to both B and I
  4. These forces create a tangential force → TORQUE

Physical setup:
  ┌─────────────────────────────────┐
  │        ARMATURE CORE            │
  │   ┌───────────────────────┐    │
  │   │   ←── Force on each  │    │
  │   │       conductor       │    │
  │   └───────────────────────┘    │
  │                                 │
  │   ⊗ ⊗ ⊗ ⊗ ⊗ ⊗ ⊗ ⊗ ⊗ ⊗        │  ⊗ = current into page
  │                                 │
  │   S ←───────────→ N            │  Field direction
  │                                 │
  │   Force = B × I × L            │
  │   Torque = Force × Radius       │
  └─────────────────────────────────┘
```

**Deriving the Torque Formula:**

```
Force on one conductor: F = B_avg × I_a × L

Where:
  B_avg = average flux density over the pole face
  I_a = armature current (per conductor)
  L = length of conductor in magnetic field

For the entire armature:
  Total force = Z × F (all Z conductors)
  But conductors are divided into A parallel paths
  So current per conductor = I_a/A (wait, that's not right)

Actually:
  Total armature current = I_a
  This divides into A parallel paths
  So current per parallel path = I_a/A
  But there are Z conductors split among A paths
  Current per conductor (in each path) = I_a/A

Actually more precisely:
  The total armature current I_a flows through the commutator
  This current enters the armature via A parallel paths
  Each path has Z/A conductors in series
  Current in each path = I_a

Force on all conductors in one pole:
  F_per_pole = (B × I_a × L) per conductor × conductors per pole
  But this is getting complex...

Let's use the POWER relationship instead:

Electrical Power = Mechanical Power (ignoring losses)
  P_in = E × I_a  (for generator)
  P_out = T × ω   (torque × angular velocity)

Since T × ω = E × I_a (for ideal machine)
  T = (E × I_a) / ω

But E = (P × Φ × N × Z) / (60 × A)
And ω = 2πN/60 = πN/30

So: T = [(P × Φ × N × Z) / (60 × A)] × I_a × (30/πN)
   T = (P × Φ × Z × I_a) / (2π × A)
   T = (P × Φ × Z × I_a) / (2A)

Wait, let me recalculate:
  T = E × I_a / ω
  T = [(PΦNZ)/(60A)] × I_a / (2πN/60)
  T = (PΦNZ × I_a × 60) / (60A × 2πN)
  T = (PΦZ × I_a) / (2πA)
```

### STEP 2 — Real Life Anchor:

**Torque in DC motors — why it matters:**

```
DC motors are used where HIGH STARTING TORQUE is needed:

1. Crane hoists:
   → Need massive torque to lift heavy loads from stationary
   → DC series motor: T ∝ I_a² → VERY high starting torque
   → When load is heavy, motor runs slower → MORE current → MORE torque

2. Electric vehicles (older):
   → Tram cars used DC series motors
   → High starting torque to accelerate from stop
   → Speed controlled by voltage

3. Paper mills, textile looms:
   → Need constant tension on material
   → DC motors provide precise torque control

4. Elevators:
   → DC compound motors for good starting torque + constant speed

The torque equation tells you:
  - How much current you need to produce a given torque
  - How speed changes with load (especially for series motors)
```

### STEP 3 — Exam Form:

$$T = \frac{P \cdot \Phi \cdot Z \cdot I_a}{2\pi \cdot A} \text{ N-m}$$

Or equivalently:
$$T = 0.159 \cdot \frac{P \cdot \Phi \cdot Z \cdot I_a}{A}$$

Where:
| Symbol | Name |
|--------|------|
| P | Number of poles |
| Φ | Flux per pole (Wb) |
| Z | Total armature conductors |
| I_a | Armature current (A) |
| A | Parallel paths (2 for wave, P for lap) |

**Simplified form:**
$$T \propto \Phi \cdot I_a$$

For a shunt motor (Φ constant): $T \propto I_a$
For a series motor (Φ ∝ I_a): $T \propto I_a^2$

| Tweak | The Trap | Counter |
|-------|----------|---------|
| 1 | "Torque at full load vs no-load" | At no-load, I_a is small, so T is small |
| 2 | "Series motor torque vs current" | T ∝ I_a² for series (Φ ∝ I) |
| 3 | "Lap vs wave wound for same torque" | A differs → torque differs |
| 4 | "Speed and torque relationship" | T = E × I_a / ω, not independent |

### STEP 5 — Practice Questions:

**Q1 (Easy - APPSC 2017):** A 4-pole DC motor has 500 conductors and is lap-wound. The flux per pole is 0.02 Wb and armature current is 50A. Find the torque developed.

**Solution:**
```
Given:
  P = 4, Z = 500, A = P = 4 (lap), Φ = 0.02 Wb, I_a = 50A

Formula: T = (P × Φ × Z × I_a) / (2π × A)
       = (4 × 0.02 × 500 × 50) / (2π × 4)
       = (20000) / (8π)
       = 2500/π
       = 795.8 N-m ≈ 796 N-m ✓
```

**Q2 (Medium - APGENCO 2018):** Compare the starting torques of a DC series motor and a DC shunt motor, both drawing 100A.

**Solution:**
```
DC SHUNT MOTOR:
  Φ is constant (field current is separate, determined by field resistance)
  T_shunt = K × Φ × I_a = K × constant × 100
  (Torque proportional to current only)

DC SERIES MOTOR:
  Φ ∝ I_a (field winding in series with armature)
  T_series = K × Φ × I_a = K × I_a × I_a = K × I_a²
  T_series = K × 100² = 10000K

RATIO: T_series / T_shunt = I_a² / (Φ × I_a) ... wait

For shunt: Φ = constant = Φ_rated at 100A? No, at 100A field current

Actually, for equal current comparison:
  T_series = K × I_a²
  T_shunt = K × Φ × I_a

Since Φ for series at 100A is similar to Φ for shunt at 100A:
  T_series = K × Φ × 100
  T_shunt = K × Φ × 100

Actually they're equal if Φ is the same!

The REAL difference is:
  - Series motor: when current is high, Φ is also high → T is VERY high
  - Shunt motor: Φ is constant, T is proportional to I_a

At starting (I_a very high):
  Series motor has EXTREMELY high starting torque (T ∝ I²)
  Shunt motor has moderate starting torque (T ∝ I)

Answer: Series motor has MUCH higher starting torque at same current
(approximately proportional to current squared vs linear)
```

## FORMULA 3: Speed Control of DC Motors

### STEP 1 — First Principles:

**Understanding DC Motor Speed:**

```
Basic speed equation:
  Back EMF: E = K × Φ × N
  Terminal voltage: V = E + I_a × R_a

  So: E = V - I_a × R_a
  K × Φ × N = V - I_a × R_a
  N = (V - I_a × R_a) / (K × Φ)

Where K = (P × Z) / (60 × A)

Since I_a × R_a is usually small compared to V:
  N ≈ V / (K × Φ)
```

**The Three Ways to Control Speed:**

```
METHOD 1: Armature Voltage Control
  → Change V (the applied voltage)
  → N ∝ V (if Φ constant)
  → Below base speed
  → Used when you need speed below rated

METHOD 2: Field Flux Control
  → Change Φ (reduce field current)
  → N ∝ 1/Φ (inverse proportionality)
  → Above base speed
  → As Φ decreases, speed INCREASES
  → Used when you need speed above rated

METHOD 3: Series Resistance Control
  → Add resistance in series with armature
  → N = (V - I_a(R_a + R_se)) / (K × Φ)
  → Inefficient (lots of power lost as heat)
  → Used for starting (not continuous control)
```

### STEP 2 — Real Life Anchor:

**Indian applications of DC motor speed control:**

```
1. DC CRANE (Steel plant, ports):
   → Ward-Leonard system: Generator-Motor set
   → Vary generator voltage to control motor speed
   → Very smooth, wide range control

2. PAPER MILLS:
   → Need precise speed control for paper tension
   → Armature voltage control with feedback
   → DC shunt motor with closed-loop control

3. ELECTRIC TRAACTION (old):
   → Series motors on locomotives
   → Series-parallel control
   → Start in series, then transition to parallel
   → Field diversion (resistance across field) for speed control

4. CNC MACHINES:
   → DC servo motors
   → Precise speed/torque control
   → Uses PWM (pulse width modulation) for voltage control

5. DOMESTIC FAN:
   → Small AC motor with AC speed control
   → Not DC, but similar concept (voltage variation)
```

### STEP 3 — Exam Form:

$$N = \frac{V - I_a R_a}{K \cdot \Phi} \text{ RPM}$$

Where $K = \frac{PZ}{60A}$

**Simplified (ignoring armature reaction):**

| Control Method | Variable | Effect on Speed |
|----------------|----------|----------------|
| Armature Voltage | N ∝ V | Linear relationship |
| Field Flux | N ∝ 1/Φ | Inverse relationship |
| Series Resistance | N decreases | Reduces effective V |

**For Series Motor:**
$$N \propto \frac{V}{\Phi} \propto \frac{V}{I_a}$$

This means: As load increases → I_a increases → Φ increases → N decreases

| Tweak | The Trap | Counter |
|-------|----------|---------|

| 2 | "Speed above base speed" | Need to reduce field (flux control) |
| 3 | "Series motor no-load" | DANGEROUS — speed becomes very high |
| 4 | "Field weakening" | Reduces Φ, increases speed, reduces torque |

### STEP 5 — Practice Questions:

**Q1 (Easy - APTRANSCO 2019):** A 220V DC shunt motor runs at 1500 RPM at rated load. Armature resistance is 0.5Ω. If the voltage is reduced to 110V, what is the new speed (assuming same load torque)?

**Solution:**
```
Given:
  V = 220V → 110V (half voltage)
  Same load torque means same I_a × Φ (approximately)
  For shunt motor, Φ is constant (field independent of armature V)

Approach:
  N₁ = (V₁ - I_aR_a) / (KΦ)
  N₂ = (V₂ - I_aR_a) / (KΦ)

Since K, Φ, I_a, R_a are the same:
  N₂/N₁ = (V₂ - I_aR_a) / (V₁ - I_aR_a)

We don't know I_a... let's assume armature drop is small.

If we ignore armature drop:
  N₂/N₁ = V₂/V₁ = 110/220 = 0.5
  N₂ = 0.5 × 1500 = 750 RPM

With armature drop (let's say I_a = 10A, R_a = 0.5):
  Armature drop = 10 × 0.5 = 5V
  N₁: (220 - 5) / KΦ = 215/KΦ
  N₂: (110 - 5) / KΦ = 105/KΦ
  N₂/N₁ = 105/215 = 0.488
  N₂ = 0.488 × 1500 = 732 RPM ≈ 733 RPM

Answer ≈ 750 RPM (ignoring drop) or ~730 RPM (with drop)
```

## FORMULA 4: DC Motor Starters

### STEP 1 — First Principles:

**Why do we need starters?**

```
At starting, the motor is stationary (N = 0).

Back EMF E = KΦN = KΦ × 0 = 0

So at start: I_a = (V - E) / R_a = V / R_a

Since R_a is very small (typically 0.1-1Ω):
  I_a_start = V / R_a = 220V / 0.5Ω = 440A

Normal full-load current might be 10-20A.
Starting current = 20-40× full-load current!

This massive current can:
  → Damage the commutator/brushes (sparking)
  → Cause voltage dip in the supply (affect other loads)
  → Trip protective devices
  → Overheat the armature windings

Solution: Limit the starting voltage (or current).
```

**Types of Starters:**

```
1. THREE-POINT STARTER (for shunt motors):
   → 3 terminals: L (line), A (armature), F (field)
   → Start: Field connected, armature connected through resistance
   → Run: Full voltage, resistance bypassed
   → Problem: If field circuit opens, motor runs away (dangerous!)

2. FOUR-POINT STARTER (improved shunt):
   → 4 terminals: L, A, F, and N (no-voltage release)
   → Has a holding coil that releases if supply fails
   → Field can open without danger

3. SERIES STARTER (for series motors):
   → No need for back EMF protection
   → Series motor naturally limits current (Φ ∝ I → T ∝ I²)
   → But starting without load is dangerous

4. COMPOUND STARTER:
   → For compound motors
   → Combines series and shunt protection
```

### STEP 2 — Real Life Anchor:

**Starters in Indian industry:**

```
1. DC CRANE in steel plant:
   → Uses Ward-Leonard system
   → Smooth starting over wide speed range
   → Gradual voltage increase through generator field control

2. DC MOTOR in DMRC (Delhi Metro):
   → Modern use: IGBT-based electronic starters
   → Soft starting (gradual voltage ramp)
   → Precise control, less mechanical stress

3. OLD TRAM SYSTEMS:
   → Series-parallel starting
   → Start both motors in series (half voltage each)
   → Then switch to parallel (full voltage)
   → This limits starting current

4. JAWS CRUSHER (mining):
   → Heavy DC series motors
   → Reduced voltage starting
   → Mechanical clutch engagement
```

### STEP 3 — Exam Form:

**Starting Current:**
$$I_{start} = \frac{V}{R_a}$$

**Current with starter resistance R_s added:**
$$I_{start} = \frac{V}{R_a + R_s}$$

**Design of starter resistance:**
For n steps, each step limits current to between I₁ (max) and I₂ (min):
$$I_1 = \frac{V}{R_1 + R_a}$$
*(first step)*

$$I_2 = \frac{V}{R_2 + R_a}$$
*(second step)*
etc.

**Time to transition between steps:**
$$t = \tau \ln\left(\frac{I_1}{I_2}\right)$$
where $\tau = L/R$ (electrical time constant)

### STEP 4 — Examiner Tweaks:

| Tweak | The Trap | Counter |
|-------|----------|---------|
| 1 | "Series motor started without load" | DANGEROUS — runs away |
| 2 | "Why shunt motor needs starter but series doesn't" | Shunt has constant Φ, series doesn't need E to limit current |
| 3 | "Three-point vs four-point starter" | Three-point: field opens = danger; Four-point: safe |
| 4 | "Starting current calculation" | I_start = V/R_a (ignoring E since E=0 at start) |

**Q1 (APPSC 2018):** A 220V DC shunt motor has armature resistance of 0.5Ω. Calculate the starting current when:

(b) Started with a starter having 2Ω series resistance

**Solution:**

## DAY 2 PM — THREE PHASE INDUCTION MOTOR

---

## FORMULA 1: Synchronous Speed and Slip

### STEP 1 — First Principles:

**What is an induction motor?**

```
An induction motor has TWO windings:
  1. Stator: 3-phase windings (stationary) — connected to supply
  2. Rotor: shorted conductors (rotates) — NOT connected to supply

How it works (like a transformer):
  1. 3-phase AC in stator → rotating magnetic field (RMF)
  2. RMF cuts rotor conductors
  3. Induced EMF in rotor (Faraday's Law)
  4. Since rotor is shorted, current flows
  5. Current-carrying rotor in magnetic field → force → torque
  6. Rotor follows the RMF (but never catches up)

The rotor ALWAYS lags behind the rotating magnetic field.
If it caught up, no relative motion → no induced EMF → no torque.
```

**Synchronous Speed (Ns):**

```
The rotating magnetic field rotates at SYNCHRONOUS SPEED.

For 3-phase with P poles at frequency f:
  Ns = 120 × f / P   (RPM)

Example (India, 50 Hz):
  2-pole motor:  Ns = 120 × 50 / 2 = 3000 RPM
  4-pole motor:  Ns = 120 × 50 / 4 = 1500 RPM
  6-pole motor:  Ns = 120 × 50 / 6 = 1000 RPM
```

**Slip:**

```
The rotor NEVER runs at synchronous speed.
It always "slips" behind.

Slip (s) = (Ns - N) / Ns

  If N = Ns: s = 0 (but this means no torque!)
  If N = 0 (starting): s = 1 (maximum slip)

Typical slip at full load: 2-5% (so rotor runs at 95-98% of Ns)
```

**Rotor Frequency:**

```
Since rotor is "cutting" the stator's RMF:
  Relative speed = Ns - N = s × Ns
  Rotor frequency fr = s × f (in Hz)

At start (s=1): fr = f (full supply frequency, 50 Hz)
At sync (s=0): fr = 0 (DC, no induced EMF)
```

### STEP 2 — Real Life Anchor:

**Induction motors in India — everywhere:**

```
Induction motors are the WORKHORSES of industry:
  → 95% of all industrial motors are induction motors
  → Cheap, robust, low maintenance

Common applications:
  1. WATER PUMPS (agriculture):
     → 5-10 HP, 3-phase
     → 4-pole, 1440 RPM (slightly less than 1500)
     → Running at ~97% of Ns → slip ~3%

  2. FAN MOTORS:
     → Ceiling fans use single-phase induction (different)
     → Industrial exhaust fans: 3-phase

  3. COMPRESSORS (HVAC, refrigeration):
     → Need constant speed
     → Running close to Ns

  4. CONVEYOR BELTS:
     → Variable speed possible with VFD
     → 4-pole, 1470 RPM typical

  5. CRANE HOISTS:
     → Usually DC or wound rotor (for speed control)
     → But many use induction with soft starters

Why induction motors dominate:
  → No brushes/slip rings (unlike synchronous/DC)
  → Self-starting
  → Cheap and reliable
```

### STEP 3 — Exam Form:

**Synchronous Speed:**
$$N_s = \frac{120 \times f}{P} \text{ RPM}$$

Where f = supply frequency (50 Hz in India)

**Slip:**
$$s = \frac{N_s - N}{N_s} = \frac{n_s - n}{n_s}$$

Or in terms of frequency:
$$s = \frac{f_r}{f}$$

Where:
| Symbol | Name | Typical Value |
|--------|------|---------------|
| s | Slip | 0.02-0.05 (2-5%) |
| Ns | Synchronous speed | 3000, 1500, 1000 RPM |
| N | Actual rotor speed | < Ns |
| fr | Rotor frequency | 1-3 Hz |

**Rotor Speed:**
$$N = N_s(1 - s) = \frac{120f}{P}(1 - s)$$

| Tweak | The Trap | Counter |
|-------|----------|---------|
| 1 | "Motor runs at Ns" | IMPOSSIBLE — no torque would be produced |
| 2 | "Slip can be negative" | No, s is always 0 < s < 1 |
| 3 | "Calculate Ns but forget f=50" | Always use f = 50 Hz for India |
| 4 | "Slip at starting" | s = 1 (at N=0) |
| 5 | "Rotor frequency at full load" | fr = s × f ≈ 0.03 × 50 = 1.5 Hz |

### STEP 5 — Practice Questions:

**Q1 (Easy - APPSC 2018):** A 4-pole, 50 Hz induction motor runs at 1440 RPM. Find:
(a) Synchronous speed
(b) Slip
(c) Rotor frequency

**Solution:**
```
Given: P = 4, f = 50 Hz, N = 1440 RPM

(a) Ns = 120 × 50 / 4 = 6000 / 4 = 1500 RPM

(b) s = (Ns - N) / Ns = (1500 - 1440) / 1500 = 60/1500 = 0.04 = 4%

(c) fr = s × f = 0.04 × 50 = 2 Hz
```

**Q2 (Medium - APGENCO 2019):** A 6-pole induction motor operates at 980 RPM with supply frequency 50 Hz. Calculate slip and rotor current frequency.

**Solution:**
```

Ns = 120 × 50 / 6 = 6000 / 6 = 1000 RPM

s = (1000 - 980) / 1000 = 20/1000 = 0.02 = 2%

fr = s × f = 0.02 × 50 = 1 Hz
```

## FORMULA 2: Torque Equation of Induction Motor

### STEP 1 — First Principles:

**How does torque develop in an induction motor?**

```
It's like a transformer with a ROTATING secondary:

1. Stator creates rotating magnetic field at Ns
2. This RMF "induces" voltage in rotor (like transformer secondary)
3. Rotor is shorted → current flows
4. Current-carrying rotor in magnetic field → force F = BIL
5. Force on all rotor bars creates TORQUE

The torque depends on:
  → Strength of RMF (∝ stator voltage V)
  → Rotor current (∝ induced EMF)
  → Phase angle between B and I (determined by rotor impedance)

The rotor induced EMF is proportional to SLIP:
  E₂ ∝ s × E₁ ∝ s × V

The rotor current I₂ ∝ E₂ / Z₂ = (s × E₁) / √(R₂² + (sX₂)²)
```

**The Torque-Slip Characteristic:**

```
As slip increases from 0:
  → E₂ increases (more induced EMF)
  → I₂ increases (more current)
  → Torque increases

But at high slip:
  → Rotor reactance sX₂ becomes large
  → Current lags more
  → Power factor decreases
  → Torque actually decreases

So torque has a MAXIMUM at some slip value.

The maximum torque occurs when:
  Rotor resistance = Rotor reactance
  R₂/s = sX₂
  s = R₂ / X₂

This is the "breakdown slip"
```

### STEP 2 — Real Life Anchor:

**Induction motor torque in industry:**

```
1. MOTOR STARTING:
   → Starting torque needed to accelerate the load
   → For a pump: need ~1.5-2× rated torque to start
   → For a compressor: need ~2-3× rated torque

2. LOAD TYPES:
   → Constant torque (conveyor): T independent of N
   → Variable torque (fan/pump): T ∝ N²
   → For fans: low starting torque is OK

3. MOTOR NAMEPLATE:
   → Shows "Breakdown torque" = maximum torque motor can produce
   → Usually 2-3× rated torque
   → Motor must NOT stall under this load

4. STAR-DELTA STARTING:
   → Reduces starting voltage by 1/√3
   → Starting torque reduced to 1/3
   → Only works if load is light enough
```

### STEP 3 — Exam Form:

**Torque Equation:**
$$T = \frac{3 \times V_1^2 \times (R_2/s)}{\omega_s \times [(R_1 + R_2/s)^2 + (X_1 + X_2)^2]}$$

Where:
| Symbol | Name |
|--------|------|
| V₁ | Stator phase voltage |
| R₁, X₁ | Stator resistance and reactance |
| R₂, X₂ | Rotor resistance and reactance (referred to stator) |
| s | Slip |
| ωs | Synchronous angular velocity = 2πNs/60 |

**Maximum Torque:**
$$T_{max} = \frac{3 \times V_1^2}{2 \times \omega_s \times (X_1 + X_2)}$$

This occurs at: $s_{max} = \frac{R_2}{X_2}$

**Starting Torque (s = 1):**
$$T_{start} = \frac{3 \times V_1^2 \times R_2}{\omega_s \times [(R_1 + R_2)^2 + (X_1 + X_2)^2]}$$

### STEP 4 — Examiner Tweaks:

| Tweak | The Trap | Counter |
|-------|----------|---------|
| 1 | "T ∝ V²" — voltage reduction halves torque | Actually 1/4! (since T ∝ V²) |
| 2 | "Maximum torque depends on R₂" | NO — Tmax is INDEPENDENT of R₂ |
| 3 | "Slip at maximum torque" | smax = R₂/X₂ |
| 4 | "Adding resistance to rotor circuit" | Changes smax but NOT Tmax |
| 5 | "Starting torque calculation" | Use s=1 in torque equation |

### STEP 5 — Practice Questions:

**Q1 (APPSC 2018):** An induction motor develops maximum torque of 200 N-m at a slip of 20%. Find the rotor resistance if the rotor reactance is 5Ω.

**Solution:**
```
Given: smax = 0.20, X₂ = 5Ω

Formula: smax = R₂ / X₂
So: R₂ = smax × X₂ = 0.20 × 5 = 1Ω
```

**Q2 (APGENCO 2019):** Compare the starting torque of an induction motor when:
(a) Voltage is reduced to 80% using star-delta starter
(b) Voltage is full

**Solution:**
```
Formula: T ∝ V²

(a) Voltage = 0.8 × V
  T_start_new ∝ (0.8V)² = 0.64 × V²
  T_start_new = 0.64 × T_start_full

(b) Full voltage:
  T_start_full = T

Ratio: T_start_new / T_start_full = 0.64 / 1 = 0.64

Actually for star-delta:
  In star: Phase voltage = V/√3
  So V_phase is reduced to 1/√3 = 0.577 of line voltage
  T ∝ V²
  T_start_star = (0.577)² × T_start_delta = 0.333 × T_start_delta

So starting torque in star connection is 1/3 of delta connection.
```

## FORMULA 3: Starting Methods of Induction Motors

### STEP 1 — First Principles:

**Why special starting methods?**

```
Direct On Line (DOL) starting:
  → Full voltage applied directly
  → Starting current = 6-8 × full-load current
  → This huge current:
     - Dips voltage in the plant (affects other equipment)
     - Causes electrical stress on motor windings
     - May trip protective devices

Solution: Reduce voltage during starting.

BUT: T ∝ V²
  → Reducing voltage to 1/√3 reduces starting torque to 1/3
  → The load must be light enough to start with 1/3 torque

Different starting methods trade off between:
  → Current reduction
  → Torque reduction
```

### STEP 2 — Real Life Anchor:

**Starting methods used in Indian industry:**

```
1. DOL STARTER (small motors < 5 HP):
   → Direct connection to supply
   → Cheap, simple
   → Problem: High inrush current

2. STAR-DELTA (medium motors 5-25 HP):
   → Motor windings connected in STAR during starting
   → After starting, switch to DELTA
   → 1/3 starting torque
   → Most common in industry

3. AUTOTRANSFORMER (large motors):
   → Tap at 50-80% voltage
   → Starting torque = (tap%)² × DOL torque
   → Adjustable tap

4. SOFT STARTER (modern):
   → Electronic (thyristor-based)
   → Gradual voltage ramp
   → No mechanical stress
   → Variable ramp time

5. VFD (Variable Frequency Drive):
   → Best control
   → Start at low frequency (low voltage)
   → Ramp up frequency and voltage together
   → Most expensive but best performance
```

### STEP 3 — Exam Form:

| Method | Voltage Reduction | Starting Current | Starting Torque |
|--------|------------------|-----------------|----------------|
| DOL | 100% | 6-8 × FL | Full |
| Star-Delta | 1/√3 (57.7%) | 1/3 of DOL | 1/3 of DOL |
| Autotransformer (80%) | 80% | 0.64 × DOL | 0.64 × DOL |
| Soft Starter | Gradual | Controlled | Controlled |
| VFD | Variable | 1 × FL | Full |

### STEP 4 — Examiner Tweaks:

| Tweak | The Trap | Counter |
|-------|----------|---------|
| 1 | "Star-delta reduces voltage to half" | No, to 1/√3 = 57.7% |
| 2 | "Torque reduces by same factor as voltage" | No, torque ∝ V² |
| 3 | "DOL starting always fine" | No, only for small motors with light load |
| 4 | "Which starting method has best torque" | DOL (full voltage) or VFD (matches V/f) |

### STEP 5 — Practice Questions:

**Q1 (APTRANSCO 2018):** An induction motor has starting current of 300A at DOL. If a star-delta starter is used, what is the starting current?

**Solution:**
```
Star-delta reduces starting current to 1/3 of DOL.

I_start_star = 300 / 3 = 100 A
```

## FORMULA 1: EMF Equation of Synchronous Generator

### STEP 1 — First Principles:

**What is a synchronous machine?**

```
A synchronous machine can operate as:
  1. GENERATOR (alternator): converts mechanical → electrical
  2. MOTOR: converts electrical → mechanical

Unlike induction motor, rotor rotates at EXACTLY synchronous speed:
  N = Ns = 120f/P (always!)

How a synchronous generator works:
  1. DC excites the rotor field winding → magnetic field
  2. Rotor mechanically rotated by turbine
  3. Rotating magnetic field cuts stator windings
  4. Induces AC voltage in stator at frequency f

Synchronous speed:
  N = 120f/P
  For 50 Hz, 2-pole: N = 3000 RPM
  For 50 Hz, 4-pole: N = 1500 RPM
```

**EMF Equation — same as transformer!**

```
The stator is essentially a 3-phase winding.
The EMF induced per phase:

E = 4.44 × f × N × Φ × K

Where:
  f = supply frequency (50 Hz)
  N = turns per phase
  Φ = flux per pole
  K = winding factor (accounts for coil distribution and chording)
```

### STEP 2 — Real Life Anchor:

**Synchronous generators in India:**

```
ALL power generation in India uses synchronous generators (alternators):

1. THERMAL POWER PLANT:
   → 500 MW generator, 11 kV
   → 2-pole, 3000 RPM at 50 Hz
   → Steam turbine drives the rotor

2. HYDRO POWER PLANT:
   → 200 MW Francis/Pelton turbine
   → 4 or 6-pole, 1500 or 1000 RPM
   → Water turbine drives the rotor

3. GAS TURBINE:
   → Quick start, medium efficiency
   → 100-300 MW units

4. WIND TURBINE (older):
   → Doubly-fed induction or synchronous
   → Variable speed possible with power electronics

Synchronous generators are used because:
  → Produce power at exact frequency (50 Hz)
  → Can control reactive power via field excitation
  → Synchronized with grid
```

### STEP 3 — Exam Form:

$$E = 4.44 \times f \times N \times \Phi_m \times K_p \times K_d$$

Or:
$$E = 4.44 \times f \times \Phi \times T \times K_w$$

Where:
| Symbol | Name |
|--------|------|
| E | Generated EMF per phase (RMS) |
| f | Frequency (50 Hz in India) |
| N or T | Number of turns per phase |
| Φ | Flux per pole (Wb) |
| Kp | Pitch factor (typically 0.9-0.95) |
| Kd | Distribution factor (typically 0.9-0.95) |
| Kw | Winding factor = Kp × Kd |

**Frequency relationship:**
$$f = \frac{P \times N}{120}$$
Or: $N = \frac{120f}{P}$

### STEP 4 — Examiner Tweaks:

| Tweak | The Trap | Counter |
|-------|----------|---------|
| 1 | "E ∝ flux, but flux depends on field current" | Yes, control field to control E |
| 2 | "Why K is less than 1" | Due to coil distribution and chording |
| 3 | "Poles must be even" | Yes, P is always even for 3-phase |

### STEP 5 — Practice Questions:

**Solution:**

The rotor must rotate at EXACTLY 1500 RPM to produce 50 Hz.
If speed varies → frequency varies.
```

## FORMULA 2: Voltage Regulation

### STEP 1 — First Principles:

**What is voltage regulation?**

```
When a generator supplies load:
  → Current flows through stator winding
  → Voltage drops due to impedance
  → Terminal voltage V < induced EMF E

Voltage Regulation = how much terminal voltage drops from no-load to full-load

%VR = (E - V) / V × 100 (at constant field excitation)

Factors causing voltage drop:
  1. Armature resistance (I × Ra) — in phase with current
  2. Armature reactance (I × Xs) — leads current by 90°

Where Xs = synchronous reactance = ωLs
```

**Phasor Diagram:**

```
For lagging pf (inductive load):
  E = V + I(Ra + jXs)
    = V + I×Ra + jI×Xs

  The I×Xs drop is QUADRATURE to V (90° ahead of I)
  The I×Ra drop is IN PHASE with I

At lagging pf, E is LARGER than V
  → Regulation is POSITIVE

At leading pf (capacitive load):
  E = V - jI×Xs + I×Ra
  → The jI×Xs term can actually CANCEL some of V
  → E can be LESS than V
  → Regulation can be NEGATIVE!
```

### STEP 2 — Real Life Anchor:

**Voltage regulation in power systems:**

```
Generators must maintain CONSTANT voltage despite load changes:

1. NO-LOAD: E = V (approximately)
  → Field excitation set to give rated voltage

2. FULL-LOAD (lagging pf):
  → Voltage drops (inductive loads consume reactive power)
  → Regulation is POSITIVE (typically 5-15%)

3. FULL-LOAD (leading pf):
  → Capacitive loads SUPPLY reactive power
  → Voltage can RISE
  → Regulation can be NEGATIVE
  → Synchronous motors running over-excited do this!

4. WHY REGULATION MATTERS:
  → Load centers expect 400V ± 10%
  → Generators adjust field to maintain voltage
  → Automatic Voltage Regulator (AVR) does this continuously
```

### STEP 3 — Exam Form:

**Voltage Regulation:**
$$\%VR = \frac{E - V}{V} \times 100$$

**EMF Equation (exact):**
$$E = \sqrt{(V\cos\phi + I_a R_a)^2 + (V\sin\phi + I_a X_s)^2}$$

**Simplified (ignoring Ra):**
$$\%VR \approx \frac{I_a X_s \sin\phi}{V} \times 100$$

For lagging pf: add the drop
For leading pf: subtract the drop

### STEP 4 — Examiner Tweaks:

| Tweak | The Trap | Counter |
|-------|----------|---------|
| 1 | "Leading pf has positive regulation" | NO — leading can have NEGATIVE regulation |
| 2 | "Regulation is always positive" | Only for lagging pf |
| 3 | "Ignoring Ra when calculating" | For large machines Ra is small, but don't ignore for small machines |
| 4 | "At unity pf" | Just I×Ra drop (X×sinφ = 0) |

### STEP 5 — Practice Questions:

**Q1 (APGENCO 2019):** A 3-phase synchronous generator supplies 100 MW at 0.8 pf lagging and 11 kV. The synchronous reactance is 1.2Ω per phase. Find voltage regulation.

**Solution:**
```
Given:
  P = 100 MW, pf = 0.8 lag, V = 11 kV (line)
  Xs = 1.2Ω per phase

Step 1: Find phase voltage and current
  V_Ph = 11000/√3 = 6350 V
  S = P/pf = 100/0.8 = 125 MVA
  I = S / (√3 × V) = 125000000 / (1.732 × 11000) = 656 A

Step 2: Calculate regulation (ignoring Ra)
  %VR = I × Xs × sinφ / V_Ph × 100
  sinφ = √(1 - 0.8²) = √(1 - 0.64) = √0.36 = 0.6
  
  I × Xs = 656 × 1.2 = 787.2 V
  %VR = 787.2 × 0.6 / 6350 × 100 = 472.3 / 6350 × 100 = 7.44%

So regulation is approximately 7.4% (positive, lagging pf)
```

## FORMULA 3: V-Curves of Synchronous Motor

### STEP 1 — First Principles:

**What are V-curves?**

```
V-curves show the relationship between:
  → Armature current I_a (Y-axis)
  → Field current If (X-axis)
  at constant load power

The shape looks like a "V" (hence the name).

Why do they exist?
  1. At low field current (under-excited): motor draws LAGGING current
     → Needs to draw magnetizing current from supply
     → Current is large

  2. As field current increases:
     → Motor becomes less lagging
     → Current decreases

  3. At unity pf (minimum current):
     → Field current = field for normal excitation

  4. As field current increases further (over-excited):
     → Motor draws LEADING current (supplies reactive power)
     → Current increases again
```

### STEP 2 — Real Life Anchor:

**Synchronous motors in Indian industry:**

```
Synchronous motors are used where CONSTANT SPEED is needed:

1. COMPRESSOR DRIVES (refrigeration, air conditioning):
   → Must run at constant speed (for refrigerant compression)
   → Large motors 500-2000 HP
   → Can also correct power factor

2. TEXTILE MILLS:
   → Synchronous motors for looms
   → Maintain constant speed for quality

3. CEMENT MILLS:
   → Ball mills driven by synchronous motors
   → Heavy starting, constant speed

4. POWER FACTOR CORRECTION:
   → Over-excited synchronous motor supplies reactive power
   → Acts like a capacitor bank
   → Called "synchronous condenser"

5. HYDRO PUMPED STORAGE:
   → Generators that can run as motors
   → Pump water uphill at night (motor mode)
   → Generate during peak (generator mode)
```

### STEP 3 — Exam Form:

**V-Curve Shape:**

```
        I_a (armature current)
         │
    Min  │        ╲
         │         ╲   ← Over-excited (leading pf)
         │          ╲
         │           ╲
         │            ╲
         │             ↘
         │              ↘
         │               ╲
         │                ╲
         │           ↑    ╲
         │        Unity pf ╲
         │                 ╲ ← Under-excited (lagging pf)
         └──────────────────────→ If
              If_min

At If_min: Unity pf, minimum current
Left of If_min: Lagging pf (under-excited)
Right of If_min: Leading pf (over-excited)
```

**Key Points:**
- Synchronous motors can operate at ANY power factor
- By adjusting field, you control whether motor draws or supplies reactive power
- Over-excited motor = "capacitor" (supplies reactive power)
- Under-excited motor = "inductor" (absorbs reactive power)

### STEP 4 — Examiner Tweaks:

| Tweak | The Trap | Counter |
|-------|----------|---------|
| 1 | "Synchronous motor always runs at lagging pf" | NO — can run at unity or leading |
| 2 | "V-curves are the same for all loads" | No — the minimum point shifts with load |
| 3 | "Synchronous motor has no starting torque" | Correct — needs separate starting method |
| 4 | "Under-excited motor supplies reactive power" | NO — over-excited supplies reactive |

### STEP 5 — Practice Questions:

**Q1 (APPSC 2017):** State the advantage of synchronous motor over induction motor regarding power factor.

**Solution:**
```
ADVANTAGE: Synchronous motor can operate at UNIT POWER FACTOR

Induction motor:
  → Always operates at LAGGING pf (0.8-0.9 typically)
  → Cannot control pf
  → Draws magnetizing current from supply

Synchronous motor:
  → Can be over-excited to operate at LEADING pf
  → Can supply reactive power to the grid
  → Can be used for power factor correction
  → Can operate at unity pf (minimum current)

A synchronous motor running over-excited acts like a CAPACITOR.
This is why large industries install synchronous motors — to improve pf.
```

## FORMULA 1: Transmission Line Parameters

### STEP 1 — First Principles:

**Why do we need transmission lines?**

```
Power is generated at 11-33 kV (convenient for generators)
Power is used at 400V-11 kV (convenient for consumers)

But: P = V × I
  For same power, HIGHER voltage → LOWER current
  Lower current → thinner wires → less cost

So we TRANSMIT at high voltage (400 kV, 220 kV, 132 kV)
Then step DOWN for distribution.

India's grid:
  Generation: 11 kV (generators)
  Primary Transmission: 400 kV (state grids)
  Secondary Transmission: 220 kV, 132 kV
  Distribution: 33 kV, 11 kV
  Consumer: 415V (three-phase), 240V (single-phase)
```

**Line Parameters (per phase per km):**

```
Resistance (R):
  R = ρ / A  (ohm per km)
  ρ = resistivity of conductor material
  A = cross-sectional area

Inductance (L):
  L = 2 × 10⁻⁷ × ln(D/r')  H/km
  D = distance between conductors (geometric mean distance)
  r' = effective radius (GMR = Geometric Mean Radius)
  r' = r × e^(μ/4π) × e^(-1/4) for solid conductor

Capacitance (C):
  C = 2πε / ln(D/r)  F/km
  ε = permittivity of air
  D = distance between conductors
  r = radius of conductor
```

### STEP 2 — Real Life Anchor:

**Indian transmission lines:**

```
1. 400 kV LINES (major inter-state):
   → ACSR (Aluminum Conductor Steel Reinforced)
   → Bundle conductors (2 or 4 per phase)
   → Horizontal configuration
   → Typical span: 300-400 meters

2. 220 kV LINES (state transmission):
   → ACSR conductors
   → Single or bundle conductors
   → Typical span: 250-350 meters

3. 132 kV LINES (sub-transmission):
   → ACSR or AAAC
   → Single conductor
   → Typical span: 200-300 meters

4. 33 kV LINES (rural distribution):
   → Single pole structures
   → Longer spans
   → Higher losses (lower voltage)

Parameters per km for typical 400 kV line:
  R ≈ 0.03-0.05 Ω/km
  L ≈ 1.0-1.2 mH/km
  C ≈ 0.01-0.012 μF/km
```

### STEP 3 — Exam Form:

**Resistance:**
$$R = \frac{\rho}{A} \text{ Ω/km}$$

**Inductance:**
$$L = 2 \times 10^{-7} \times \ln\left(\frac{D}{r'}\right) \text{ H/km}$$

**Capacitance:**
$$C = \frac{2\pi\varepsilon_0}{\ln(D/r)} \text{ F/km}$$

Where:
| Symbol | Value |
|--------|-------|
| ρ (Aluminum) | 2.82 × 10⁻⁸ Ω-m |
| ε₀ | 8.854 × 10⁻¹² F/m |
| r' (GMR) | r × e^(-μ/4π) ≈ r × 0.7788 |

### STEP 4 — Examiner Tweaks:

| Tweak | The Trap | Counter |
|-------|----------|---------|
| 1 | "Inductance increases with conductor radius" | Actually L ∝ ln(D/r) — larger r → smaller L |
| 2 | "Capacitance increases with spacing" | Actually C ∝ 1/ln(D/r) — larger D → smaller C |
| 3 | "GMR = physical radius" | No, GMR < physical radius |
| 4 | "D = distance between centers" | Use geometric mean distance for 3-phase |

### STEP 5 — Practice Questions:

**Q1 (APTRANSCO 2018):** Calculate the inductance of a 3-phase transmission line with conductors spaced 5m apart in equilateral formation. Conductor radius is 1.5 cm.

**Solution:**
```
Given:
  D = 5 m (equilateral spacing)
  r = 0.015 m

GMR r' = r × 0.7788 = 0.015 × 0.7788 = 0.01168 m

L = 2 × 10⁻⁷ × ln(D/r') H/m
  = 2 × 10⁻⁷ × ln(5/0.01168) × 1000 m
  = 2 × 10⁻⁴ × ln(427.4)
  = 2 × 10⁻⁴ × 6.057
  = 1.21 × 10⁻³ H/km
  = 1.21 mH/km ✓
```

## FORMULA 2: Per Unit System

### STEP 1 — First Principles:

**Why per unit?**

```
In power systems, we have:
  → Voltages: 400 kV, 220 kV, 132 kV, 33 kV, 11 kV, 415V...
  → Currents: from amps to thousands of amps
  → Impedances: from milliohms to kiloohms
  → Powers: from kW to GW

It's hard to work with all these numbers.
PER UNIT simplifies everything!

Choose BASE values:
  → Base MVA (S_base) — usually 100 MVA or 10 MVA
  → Base kV (V_base) — the voltage level you're working at

Then:
  Z_pu = Z_actual / Z_base
  I_pu = I_actual / I_base
  V_pu = V_actual / V_base

Where:
  Z_base = V_base² / S_base
  I_base = S_base / V_base
```

**Changing bases:**

```
A device has Z_pu on its OWN rating.
We need Z on SYSTEM base.

Z_new = Z_old × (MVA_new / MVA_old) × (kV_old / kV_new)²

This is crucial when combining different components.
```

### STEP 2 — Real Life Anchor:

**Per unit in Indian grid studies:**

```
Per unit is used in ALL power system analysis:

1. LOAD FLOW studies:
  → All bus voltages in pu
  → Line flows in pu
  → Typical base: 100 MVA or 500 MVA

2. FAULT calculations:
  → Fault currents in pu
  → Convert back to kA using I_base

3. STABILITY studies:
  → All machine parameters in pu
  → Compare different machines easily

4. TRANSFORMER studies:
  → Each winding has different voltage
  → Per unit keeps it consistent
  → Z_pu is same for all windings when referred
```

### STEP 3 — Exam Form:

**Base Quantities:**
$$S_{base} \text{ (MVA)}, V_{base} \text{ (kV at that level)}$$
$$Z_{base} = \frac{V_{base}^2}{S_{base}} \text{ Ω}$$
$$I_{base} = \frac{S_{base}}{\sqrt{3} \times V_{base}} \text{ kA}$$

**Per Unit Conversion:**
$$Z_{pu} = \frac{Z_{actual}}{Z_{base}} = Z_{actual} \times \frac{S_{base}}{V_{base}^2}$$

**Changing Base:**
$$Z_{new} = Z_{old} \times \left(\frac{MVA_{new}}{MVA_{old}}\right) \times \left(\frac{kV_{old}}{kV_{new}}\right)^2$$

### STEP 4 — Examiner Tweaks:

| Tweak | The Trap | Counter |
|-------|----------|---------|
| 1 | "Use wrong voltage for base" | Must use voltage AT THAT level (line-to-line) |
| 2 | "Forget to convert kV to V" | Keep units consistent! |
| 3 | "Different base MVA for different components" | Convert ALL to same base |
| 4 | "Forgetting the squared term" | kV² appears in Z_base |

### STEP 5 — Practice Questions:

**Q1 (APPSC 2018):** A transformer has 10% impedance on its own rating of 20 MVA, 11 kV/132 kV. Find Z in ohms on a 100 MVA base.

**Solution:**
```
Given:
  Z_pu_own = 0.10 pu on 20 MVA, 11 kV base (LV side)
  We need to find Z on 100 MVA base at same 11 kV

Z_base_old = V²/S = 11²/20 = 121/20 = 6.05 Ω (LV side)

Z_actual = Z_pu × Z_base = 0.10 × 6.05 = 0.605 Ω

Z_base_new = 11²/100 = 121/100 = 1.21 Ω

Z_pu_new = Z_actual / Z_base_new = 0.605 / 1.21 = 0.50 pu

Or using formula:
  Z_new = Z_old × (MVA_new/MVA_old) × (kV_old/kV_new)²
  Z_new = 0.10 × (100/20) × (11/11)²
  Z_new = 0.10 × 5 × 1 = 0.50 pu ✓
```

## FORMULA 1: Symmetrical Components

### STEP 1 — First Principles:

**Why do we need symmetrical components?**

```
When a fault occurs, currents become ASYMMETRICAL (unbalanced).
Analyzing unbalanced 3-phase systems is very difficult.

SYMMETRICAL COMPONENTS breaks one unbalanced system into
THREE balanced systems:

  1. POSITIVE SEQUENCE:      3 phasors, 120° apart, same magnitude
                              Rotates in normal direction (R-Y-B)

  2. NEGATIVE SEQUENCE:      3 phasors, 120° apart, same magnitude
                              Rotates in opposite direction (R-B-Y)

  3. ZERO SEQUENCE:          3 phasors, all in PHASE (0° apart)
                              No rotation
```

**The 'a' operator:**

```
'a' = 1 ∠ 120° = -0.5 + j0.866

Properties:
  a² = 1 ∠ 240° = -0.5 - j0.866
  1 + a + a² = 0
  a³ = 1

Useful relations:
  a² = a' (complex conjugate of a)
  a - a² = j√3
  1 - a = (3/2) - j(√3/2)
```

### STEP 2 — Real Life Anchor:

**Faults in Indian power system:**

```
Common faults and their sequence components:

1. THREE-PHASE FAULT (3-φ to ground):
   → Symmetrical fault
   → Only POSITIVE sequence
   → Most severe but rarest (5%)

2. LINE-TO-GROUND FAULT (L-G):
   → Most common (70-80% of faults)
   → All three sequences present
   → Usually caused by lightning or conductor break

3. LINE-TO-LINE FAULT (L-L):
   → Second most common (15-20%)
   → Positive and negative sequences only
   → Usually caused by conductor clash

4. DOUBLE LINE-TO-GROUND (L-L-G):
   → All three sequences
   → Most complex

Indian Grid:
  → 400 kV lines prone to lightning
  → L-G faults most common
  → Protection: distance relays, differential relays
```

### STEP 3 — Exam Form:

**Transformation (using matrix):**

$$[\begin{pmatrix}V_0\\V_1\\V_2\end{pmatrix}] = \frac{1}{3}[\begin{pmatrix}1&1&1\\1&a&a^2\\1&a^2&a\end{pmatrix}][\begin{pmatrix}V_R\\V_Y\\V_B\end{pmatrix}]$$

**Inverse:**
$$[\begin{pmatrix}V_R\\V_Y\\V_B\end{pmatrix}] = [\begin{pmatrix}1&1&1\\1&a^2&a\\1&a&a^2\end{pmatrix}][\begin{pmatrix}V_0\\V_1\\V_2\end{pmatrix}]$$

**Sequence Currents:**
$$I_0 = (I_R + I_Y + I_B)/3$$
$$I_1 = (I_R + aI_Y + a^2I_B)/3$$
$$I_2 = (I_R + a^2I_Y + aI_B)/3$$

### STEP 4 — Examiner Tweaks:

| Tweak | The Trap | Counter |
|-------|----------|---------|
| 1 | "Zero sequence current in balanced load" | Always zero for balanced conditions |
| 2 | "Zero sequence in delta connection" | Delta doesn't draw zero sequence current |
| 3 | "a² vs a" in formula | Be careful: V₁ uses a, V₂ uses a² |
| 4 | "L-L-G vs L-G" | L-L-G has two phases to ground, more complex |

### STEP 5 — Practice Questions:

**Q1 (APPSC 2017):** Calculate the symmetrical components of I_R = 10∠0°, I_Y = 10∠-120°, I_B = 10∠120°.

**Solution:**
```
These are BALANCED phasors (R-Y-B sequence, equal magnitude).

I₁ = (I_R + aI_Y + a²I_B)/3
  a = 1∠120°, a² = 1∠240°
  
  I₁ = (10∠0 + a×10∠-120 + a²×10∠120) / 3
  = (10 + 10∠0 + 10∠0) / 3   ← since a×1∠-120 = 1∠0, etc.
  = (10 + 10 + 10) / 3
  = 30/3 = 10∠0° pu

I₂ = (I_R + a²I_Y + aI_B)/3
  = (10∠0 + a²×10∠-120 + a×10∠120) / 3
  = (10 + 10∠240 + 10∠240) / 3 ← wait

Actually: a²×1∠-120 = 1∠240 × 1∠-120 = 1∠120
         a×1∠120 = 1∠120 × 1∠120 = 1∠240
  
  I₂ = (10 + 10∠120 + 10∠240) / 3 = 0

I₀ = (I_R + I_Y + I_B) / 3 = 0

So this balanced set has only positive sequence ✓
```

## FORMULA 1: Circuit Breakers + Protection

### STEP 1 — First Principles:

**Why do we need protection?**

```
When fault occurs:
  → Current becomes HUGE (10-50× normal)
  → Equipment heats up quickly
  → Mechanical forces damage conductors
  → Voltage dips affect entire system

Protection = detect fault + isolate quickly + minimize damage

The PROTECTION ZONE concept:
  Each equipment (generator, transformer, line) has its own protection
  Zones overlap slightly to ensure no blind spots

Protection must be:
  1. FAST — clear fault before damage
  2. SELECTIVE — isolate only the faulty section
  3. SENSITIVE — detect even small faults
  4. RELIABLE — works when needed
```

### STEP 2 — Real Life Anchor:

**Protection in Indian grid:**

```
400 kV Substation Protection:
  → Each line protected by TWO independent relays
  → Primary: Distance relay (zone 1, 2, 3)
  → Backup: Overcurrent relay
  → Breaker: SF6 gas, 4000 A, 40 kA

Protection philosophy:
  → If line fault: trip both ends quickly (80 ms)
  → If bus fault: trip all feeders (100 ms)
  → If transformer fault: trip transformer + bus (200 ms)

Types of relays:
  → Electromechanical (old, but still used)
  → Static (transistor-based)
  → Numerical (microprocessor-based) — modern
```

### STEP 3 — Exam Form:

**Circuit Breaker Rating:**

**Making Current:**
$$I_{making} = 2.55 \times I_{break}$$

**Protection Zones:**
| Zone | Reach | Time |
|------|-------|------|
| Zone 1 | 80% of line | Instantaneous |
| Zone 2 | 120% of line + 50% of next | 0.3-0.5s |
| Zone 3 | 100% of next + 50% of next-next | Backup |

## FORMULA 2: Power System Stability

### STEP 1 — First Principles:

**What is stability?**

```
A power system is STABLE if, after a disturbance:
  → All generators return to SYNCHRONISM
  → Voltages and frequencies return to normal

Types of stability:

1. STEADY-STATE STABILITY:
   → Small, slow disturbances
   → System adjusts gradually
   → Usually not a problem

2. TRANSIENT STABILITY:
   → LARGE disturbance (fault, sudden load change)
   → Machines swing against each other
   → Must stay in synchronism for 1-5 seconds

3. VOLTAGE STABILITY:
   → Load increases beyond transfer capability
   → Voltage collapses
   → Not about frequency/synchronism
```

### STEP 2 — Real Life Anchor:

**India's grid stability challenges:**

```
India's grid (POSOCO):
  → 400 kV links between states
  → Large power transfers North→South, East→West
  → Maintaining stability is critical

August 2012 blackout (north India):
  → 400 kV line tripped
  → Other lines overloaded
  → Cascading failure
  → 600 million without power

How India prevents blackouts:
  → AFC (Automatic Frequency Control)
  → Grid containment reserves
  → Under-frequency load shedding
  → Rate of change of frequency protection (RoCoF)
```

### STEP 3 — Exam Form:

**Swing Equation:**
$$\frac{2H}{\omega_s} \cdot \frac{d^2\delta}{dt^2} = P_m - P_e$$

Where:
| Symbol | Name |
|--------|------|
| H | Inertia constant (MW-s/MVA) |
| δ | Power angle (rad) |
| Pm | Mechanical input |
| Pe | Electrical output = (EV/X)sinδ |

**Equal Area Criterion:**
```
If Area A1 (accelerating) = Area A2 (decelerating):
  → System is STABLE

If A1 > A2:
  → System is UNSTABLE
  → δ keeps increasing → loss of synchronism
```

### STEP 4 — Examiner Tweaks:

| Tweak | The Trap | Counter |
|-------|----------|---------|
| 1 | "Stable = no oscillation" | Transient: some oscillation OK, must damp out |
| 2 | "Equal area means equal" | Means A1 = A2 for STABLE |
| 3 | "Fault clearing time" | Faster clearing → more stable |

### STEP 5 — Practice Questions:

**Q1 (APGENCO 2018):** Explain equal area criterion for transient stability.

**Solution:**
```
EQUAL AREA CRITERION:

After a fault:
  1. Mechanical power Pm is suddenly reduced (if fault reduces electrical output)
  2. Mechanical power Pm > Electrical power Pe
  3. Rotor ACCELERATES (gains kinetic energy)

When fault clears:
  1. Electrical power suddenly increases
  2. Now Pe > Pm
  3. Rotor DECELERATES (loses kinetic energy)

The area between Pm and Pe curve on δ-ω diagram:
  A1 = acceleration area (during fault)
  A2 = deceleration area (after fault)

STABLE: A1 = A2 (energy absorbed = energy released)
UNSTABLE: A1 > A2 (system has excess kinetic energy, δ keeps increasing)
```

## FORMULA 3: Neutral Earthing & Insulators

### STEP 1 — First Principles:

**Why do we ground the neutral?**
```
Neutral grounding provides:
  1. Reference point for phase voltages
  2. Path for ground fault current to flow
  3. Protection against overvoltages
  4. Safety for personnel and equipment
```

**Methods of neutral earthing:**
```
1. SOLID EARTHING (Z0 ≈ 0):
   → Most common for HV transmission (>33 kV)
   → High SLG fault current → fast protection
   → Requires high-rated breakers

2. RESISTANCE EARTHING (Z0 = 3Rn):
   → Limits SLG fault current to safe level
   → Used in generators (limits damage to stator core)
   → Low, medium, or high resistance types

3. REACTANCE EARTHING (Z0 = j3Xn):
   → Limited use; limits fault current reactively
   
4. UNGROUNDED (Z0 = ∞):
   → No path for SLG current
   → System capacitance provides small capacitive current
   → Difficult to detect first ground fault
   
5. PETERSON COIL (ARC SUPPRESSION COIL):
   → Tuned inductor between neutral and ground
   → Cancels line-to-ground capacitance at fault point
   → Extinguishes arcing ground faults automatically
   → Used in EHV systems (220 kV, 400 kV)
```

**Effect on zero-sequence impedance:**
| Earthing | Z0 in sequence network | SLG fault current |
|---|---|---|
| Solid | Small (≈ Z1) | HIGH |
| Resistance | Zgen,0 + 3Rn | Intermediate |
| Ungrounded | ∞ | Zero (capacitive only) |
| Peterson coil | Zgen,0 + j(3XL - XC) | Near zero (tuned) |

### STEP 2 — Real Life Anchor:

```
In APTransco's 220 kV substations:
  → Transformer neutrals are solidly earthed
  → Generator neutrals are resistance-earthed (limits stator damage)
  → 400 kV lines sometimes use Peterson coils
  
Every distribution transformer (11kV/415V) in India:
  → Star side neutral is solidly earthed (provides safe 240V)
  → Earth resistance < 5Ω per IE rules
```

### STEP 3 — Exam Form:

**Effect of earthing on Z0 (in sequence network):**
- Solid: Z0 = Zgen,0 (small)
- Resistance: Z0 = Zgen,0 + 3Rn
- Ungrounded: Z0 = ∞ → SLG fault current = 0

**Insulators (String Efficiency):**
- eta = V / (n × Vn) × 100%
- V = total voltage across string
- Vn = voltage across disc nearest conductor
- n = number of discs
- Efficiency IMPROVES by: longer cross-arms, grading rings, static shielding

### STEP 4 — Examiner Tweaks:

| Tweak | The Trap | Counter |
|---|---|---|
| 1 | "Solidly earthed → high SLG fault current" | YES — this is correct, not a problem |
| 2 | "Ungrounded — find SLG fault current" | It's capacitive: small, but can sustain |
| 3 | "Generator earthing method?" | Resistance earthing (to limit fault damage) |
| 4 | "Which disc has highest voltage drop?" | Disc nearest to conductor (bottom in suspension) |

### STEP 5 — Practice:

**Q1 (TRANSCO 2018):** A 220 kV system has transformer neutrals solidly earthed. The zero-sequence impedance per phase is 0.1 pu. Find the SLG fault current in pu and kA at a substation bus if positive and negative impedances are also 0.1 pu. Base MVA = 100.
```
For SLG fault: If = 3V / (Z0 + Z1 + Z2)
  = 3 × 1.0 / (0.1 + 0.1 + 0.1) = 3/0.3 = 10 pu
  
I_base = 100 / (√3 × 220) = 0.262 kA
If = 10 × 0.262 = 2.62 kA

If this were ungrounded: Z0 = ∞ → If ≈ 0 (just capacitive)
→ No ground path means an SLG fault is hard to detect!
```

### STEP 1 — First Principles:

**What is an SCR?**

```
SCR = Silicon Controlled Rectifier
     = Power switch that can be turned ON by a gate pulse
     = Cannot be turned OFF by gate (unlike MOSFET, IGBT)

Structure: 4-layer device (P-N-P-N)
  → ANODE (positive)
  → GATE (control)
  → CATHODE (negative)

How it works:
  1. Without gate pulse: blocks forward voltage
  2. With gate pulse: turns ON when forward voltage exceeds V_BO
  3. Once ON: stays ON until current drops below I_H (holding current)
  4. Gate cannot turn it OFF
```

### STEP 2 — Real Life Anchor:

**SCR in Indian power systems:**

```
1. HT POWER CONTROL (electric furnaces):
   → 440V, hundreds of amps
   → Phase angle control of voltage
   → Temperature control

2. DC MOTOR DRIVES:
   → Chopper circuits
   → Control DC motor speed
   → Steel rolling mills

3. BATTERY CHARGING:
   → Controlled rectifiers
   → Taper charging for lead-acid batteries
   → 12V-48V batteries

4. STATIC VAR COMPENSATORS:
   → TCR (Thyristor Controlled Reactor)
   → For reactive power control
   → Used in 400 kV substations
```

### STEP 3 — Exam Form:

**SCR Characteristics:**
| Parameter | Symbol | Typical Value |
|-----------|--------|---------------|
| Forward blocking voltage | V_DRMc | 400-2400V |
| On-state current | I_T | 100-3000A |
| Gate trigger voltage | V_GT | 2-4V |
| Gate trigger current | I_GT | 10-200 mA |
| Holding current | I_H | 5-50 mA |
| Latching current | I_L | 2-3 × I_H |

**Turn ON:**
- Apply gate pulse when anode is positive
- V_F > V_BO (forward breakover)

**Turn OFF:**
- Reduce current below I_H
- Or force current to zero (commutation)

### STEP 4 — Examiner Tweaks:

| Tweak | The Trap | Counter |
|-------|----------|---------|
| 1 | "SCR can be turned off by gate" | NO — needs external circuit |
| 2 | "Holding vs latching current" | I_L > I_H; I_H needed to stay ON |
| 3 | "I_GT same for all SCRs" | No — check datasheet |

### STEP 5 — Practice Questions:

**Q1 (APTRANSCO 2019):** Explain why SCR is called a "controlled" rectifier.

**Solution:**
```
SCR = Silicon Controlled Rectifier

"Rectifier" because:
  → Allows current flow in ONE direction only
  → Converts AC to DC

"Controlled" because:
  → The point at which it starts conducting can be CONTROLLED
  → Using gate pulse, you can delay when it turns ON
  → This controls the average DC voltage

Without control: Diode conducts from 0° onward ( uncontrolled)
With SCR: Conducts from α° onward ( controlled by gate)

α = firing angle = angle at which gate pulse is applied
V_dc = (V_m/π)(1 + cosα) for single-phase half-controlled

This is used to:
  → Control DC motor speed
  → Control power to heaters
  → Control battery charging
```

## FORMULA 2: Controlled Rectifiers

### STEP 1 — First Principles:

**Types of Rectifiers:**

```
1. UNCONTROLLED (diodes):
   → Fixed DC output
   → V_dc = 2V_m/π (single-phase full wave)

2. CONTROLLED (SCRs):
   → Variable DC output
   → Controlled by firing angle α
   → V_dc varies from maximum to zero

3. HALF-CONTROLLED (SCR + diode):
   → Cheaper
   → Can't achieve true DC reversal
```

### STEP 2 — Real Life Anchor:

**Rectifiers in Indian industry:**

```
DC motor drives (最重要的):
  → Steel rolling mills: 6-pulse rectifier, 1000V, 5000A
  → Cement mills: 6-pulse, 440V, 1000A
  → Paper mills: 12-pulse for smoother DC

Battery charging:
  → Single-phase controlled rectifier
  → Taper charging for 12V car batteries
  → Constant voltage then constant current

Electrolysis (aluminum):
  → Very large rectifiers
  → 100 kA DC at 500V
  → 12 or 24-pulse for ripple reduction
```

### STEP 3 — Exam Form:

**Single-phase half-controlled:**
$$V_{dc} = \frac{V_m}{2\pi}(1 + \cos\alpha)$$

**Single-phase fully controlled:**
$$V_{dc} = \frac{2V_m}{\pi}\cos\alpha$$

**Three-phase fully controlled:**
$$V_{dc} = \frac{3\sqrt{2}V_{LL}}{\pi}\cos\alpha$$

Where α = firing angle (0° to 90° for rectification)

### STEP 4 — Examiner Tweaks:

| Tweak | The Trap | Counter |
|-------|----------|---------|
| 1 | "α = 90° means full voltage" | NO — α=0° is full voltage |
| 2 | "For inversion, α > 90°" | Yes, 90° to 180° |
| 3 | "6-pulse vs 12-pulse" | 12-pulse = less ripple, needs phase-shifting transformer |

### STEP 5 — Practice Questions:

**Q1 (APPSC 2018):** A single-phase fully controlled rectifier supplies 100V DC to a load. Find the firing angle if input is 230V AC.

**Solution:**
```
Given: V_dc = 100V, V_s = 230V RMS

For single-phase fully controlled:
  V_dc = (2V_m/π) × cosα
  V_m = V_s × √2 = 230 × 1.414 = 325.3V
  
  100 = (2 × 325.3 / π) × cosα
  100 = 207.1 × cosα
  cosα = 100/207.1 = 0.483
  α = cos⁻¹(0.483) = 61.1°
```

## FORMULA 5: SCR Turn-On & Commutation Methods

### SCR Turn-On Methods:
```
1. GATE PULSE (normal method):
   → Apply IG > IGT between gate and cathode
   → SCR latches ON (gate loses control after)
   
2. FORWARD VOLTAGE > VBO (undesired):
   → Breaks blocking region → destroys SCR
   → Prevented by proper voltage derating

3. dv/dt TRIGGERING (undesired):
   → Rapid rise in voltage causes capacitive charging of junction
   → Can trigger SCR even without gate pulse
   → Prevented by RC SNUBBER across the SCR

4. LIGHT TRIGGERING (LASCR):
   → Light activates thyristor
   → Used in HVDC (optical isolation)

5. TEMPERATURE:
   → Leakage current increases with temp
   → Can trigger at lower voltage

🚩 TRAP: IL > IH always. IL = latching current (after gate removed),
IH = holding current (below which SCR turns off).
```

### SCR Commutation (Turn-Off) Methods:
```
For AC circuits: Natural commutation (Line commutation)
  → AC voltage reverses polarity → current zero → SCR turns off
  → Used in phase-controlled rectifiers

For DC circuits: Forced commutation needed (4 types):

CLASS A (Resonant Load):
  → LC resonant circuit forces anode current through zero
  → Current zero → SCR turns off
  → Used in inverters

CLASS B (Resonant Pulse):
  → Auxiliary SCR + LC circuit momentarily reverse-biases main SCR
  → Main SCR current falls below IH

CLASS C (Complementary Commutation):
  → Auxiliary SCR diverts current from main SCR
  → Both SCRs must be turned off properly

CLASS D (Line/AC Commutation):
  → Natural as AC voltage reverses
  → Used in all AC-phase controlled circuits

For DC: forced commutation always needed.
For AC: natural commutation at current zero — no extra circuit needed.
```

### Cycloconverter (AC → AC, no DC link):
```
  → Direct AC frequency conversion
  → Output frequency fo < input frequency fi
  → Typically fo/fi ≤ 1/3 (otherwise harmonics severe)
  → 36-thyristor 3-φ to 3-φ standard configuration
  → Used in: cement mill drives, mine hoists (very low speed, high power)
  → Disadvantage: poor input PF, large harmonics
```

### SVPWM (Space Vector PWM):
```
  → Modern VFD technique
  → V1,max = Vdc/√3 (about 15% more output than SPWM for same DC bus)
  → Better DC bus utilization
  → Lower THD than SPWM
  → Standard in all modern VFDs
```

## FORMULA 1: Transfer Function + Block Diagrams

### STEP 1 — First Principles:

**What is a transfer function?**

```
Transfer Function G(s) = Output / Input
  → For a LINEAR system
  → In Laplace domain (s = σ + jω)
  → Assumes all initial conditions = 0

G(s) = Y(s) / X(s)

Example: RC circuit
  Input: voltage Vin
  Output: voltage Vc across capacitor
  
  Transfer function: Vc/Vin = 1/(1 + sRC)
```

### STEP 2 — Real Life Anchor:

```
Control systems everywhere in electrical engineering:

1. DC MOTOR SPEED CONTROL:
   → Input: desired speed
   → Output: actual speed
   → Feedback: tachogenerator

2. AUTOMATIC VOLTAGE REGULATOR (AVR):
   → Input: reference voltage
   → Output: generator terminal voltage
   → Feedback: voltage transformer

3. TEMPERATURE CONTROL (heater):
   → Input: set temperature
   → Output: actual temperature
   → Feedback: thermocouple

4. PLLs (Phase Locked Loop):
   → Input: reference frequency
   → Output: synthesized frequency
   → Used in inverters, motor drives
```

### STEP 3 — Exam Form:

**Block Diagram Reduction:**

| Connection | Transfer Function |
|------------|------------------|
| Series | G₁ × G₂ |
| Parallel (add) | G₁ + G₂ |
| Parallel (subtract) | G₁ - G₂ |
| Feedback (negative) | G / (1 + GH) |
| Feedback (positive) | G / (1 - GH) |

**For negative feedback CLTF:**
$$T(s) = \frac{G(s)}{1 + G(s)H(s)}$$

### STEP 4 — Examiner Tweaks:

| Tweak | The Trap | Counter |
|-------|----------|---------|
| 1 | "Moving summing junction" | Can't just move — must account for what passes through |
| 2 | "Sign in feedback" | Negative = 1+GH; positive = 1-GH |
| 3 | "Transfer function of feedback system" | Use the formula, don't derive each time |

### STEP 5 — Practice Questions:

**Q1 (APPSC 2018):** Find the closed-loop transfer function for a system with G(s) = 10/(s+2) and H(s) = 1.

**Solution:**
```
For negative feedback:
T(s) = G / (1 + GH)
     = [10/(s+2)] / [1 + 10/(s+2)]
     = 10 / [(s+2) + 10]
     = 10 / (s + 12)

This is a first-order system with time constant = 1/12 seconds
DC gain = 10/12 = 0.833
```

## FORMULA 2: Routh-Hurwitz Stability Criterion

### STEP 1 — First Principles:

**What is stability?**

```
A system is STABLE if:
  → Output remains bounded for bounded input
  → All poles of transfer function are in LEFT half plane (LHP)

STABLE:    All poles in LHP → e^(-σt) → decays to zero
UNSTABLE:  Any pole in RHP → e^(+σt) → grows without bound
MARGINAL:  Poles on imaginary axis → sustained oscillation

ROUTH-HURWITZ tells us IF poles are in RHP without finding them.
```

### STEP 2 — Real Life Anchor:

```
Stability in control systems:

1. DC MOTOR with feedback:
   → If gain too high → oscillation → unstable
   → Must damp properly

2. POWER SYSTEM FREQUENCY:
   → Low inertia systems can become unstable
   → RoCoF protection trips before instability

3. AUDIO AMPLIFIER:
   → Too much gain → oscillation at speaker
   → Heard as howling/humming
```

### STEP 3 — Exam Form:

**Routh Array:**
```
For characteristic equation: a₀s^n + a₁s^(n-1) + ... + aₙ = 0

Build Routh array:
  sⁿ:    a₀    a₂    a₄ ...
  sⁿ⁻¹:  a₁    a₃    a₅ ...
  sⁿ⁻²:  b₁    b₂    ...
  sⁿ⁻³:  c₁    c₂    ...

Where:
  b₁ = (a₁a₂ - a₀a₃)/a₁
  b₂ = (a₁a₄ - a₀a₅)/a₁
  etc.

STABILITY: ALL elements in first column > 0
UNSTABLE:  Any sign change in first column
```

### STEP 4 — Examiner Tweaks:

| Tweak | The Trap | Counter |
|-------|----------|---------|
| 1 | "All coefficients positive" | Necessary but not sufficient |
| 2 | "Row of zeros" | Use auxiliary polynomial |
| 3 | "Sign changes count" | Each change = one RHP pole |

### STEP 5 — Practice Questions:

**Q1 (APGENCO 2019):** Check stability of s³ + 5s² + 10s + 10 = 0.

**Solution:**
```
Routh array:
  s³:  1    10
  s²:  5    10
  s¹:  (5×10 - 1×10)/5 = 8     0
  s⁰:  10

First column: 1, 5, 8, 10 → all positive → STABLE ✓

No sign changes → stable system
```

## FORMULA 4: Mason's Gain Formula (Signal Flow Graphs)

### STEP 1 — First Principles:
```
Mason's formula finds the transfer function directly from the signal flow graph:
  T = (1/Δ) × Σ(Pk × Δk)

Where:
  Pk = gain of k-th forward path
  Δ = 1 - Σ(Li) + Σ(LiLj) - Σ(LiLjLk) + ...
  Li = gain of i-th loop
  LiLj = product of two NON-TOUCHING loops
  Δk = Δ after removing all loops touching the k-th forward path

Non-touching = NO shared nodes or branches between loops
```

### STEP 2 — Real Life Anchor:
```
Signal flow graphs are used in:
  1. Control system block diagram reduction (faster than block algebra)
  2. Power system stability analysis
  3. Digital filter design (DSP)
```

### STEP 3 — Exam Form:
```
Example:
  System with 2 forward paths:
    P1 = G1G2G3G4, P2 = G1G4
  Loops:
    L1 = -G2H1, L2 = -G4H2, L3 = -G2G3H2
  Non-touching: L1 and L2 (they don't share nodes)
  
  Δ = 1 - (L1+L2+L3) + (L1×L2)
  Δ1 = 1 - L2 (since L2 doesn't touch path 1) 
     wait, actually we remove loops touching path 1
  Need to be careful: Δk = Δ with all loops that touch path k removed
```

🚩 EXAMINER TRAP: Non-touching means NO shared nodes. Even touching at one node means they ARE touching.

## FORMULA 5: Compensators & PID Control

### STEP 1 — First Principles:

**Lag Compensator:**
```
Gc(s) = (1 + sT) / (1 + sαT)  where α > 1
  → Pole at 1/(αT), Zero at 1/T
  → Zero > Pole (zero at higher freq)
  → Effect: Reduces steady-state error, slightly reduces bandwidth
  → PHASE LAG: adds negative phase at mid frequencies
  → Use when: transient response is OK but steady-state error is too high
```

**Lead Compensator:**
```
Gc(s) = (1 + sT) / (1 + sαT)  where α < 1
  → Zero at 1/T, Pole at 1/(αT)
  → Zero < Pole (zero at lower freq)
  → Effect: Increases bandwidth, improves transient response
  → PHASE LEAD: adds positive phase at mid frequencies
  → Use when: transient response is too slow, steady-state error is OK
```

**PID Controller:**
```
u(t) = Kp × e(t) + Ki × ∫e(t)dt + Kd × de(t)/dt

| Term | Effect | Trade-off |
|------|--------|-----------|
| Kp (Proportional) | Reduces rise time | Increases overshoot |
| Ki (Integral) | Eliminates steady-state error | Slows response, can cause oscillation |
| Kd (Derivative) | Increases damping, reduces overshoot | Amplifies noise |

Transfer function: Gc(s) = Kp + Ki/s + Kd·s = (Kd·s² + Kp·s + Ki)/s

Ziegler-Nichols tuning: Empirical rules for PID gains based on step response.
```

### STEP 2 — Real Life Anchor:
```
PID controllers are EVERYWHERE:
  1. AVR (Automatic Voltage Regulator) of generators — PI control
  2. Temperature control in furnaces — PID
  3. Motor speed control in VFDs — PI (derivative rarely used due to noise)
  4. Grid frequency control (AGC) — PI
```

### STEP 3 — Exam Form:

**Quick identification:**
```
  Lag: Pole < Zero (α > 1) → reduces error, slows response
  Lead: Zero < Pole (α < 1) → faster response, amplifies noise
  Lead-Lag: Both, combined for best of both worlds
```

## FORMULA 6: State-Space Analysis (Basics)

### STEP 1 — First Principles:
```
State equation:  ẋ = A·x + B·u
Output equation: y = C·x + D·u

Where:
  x = state vector (n×1)
  u = input vector
  y = output vector
  A = system matrix (n×n)
  B = input matrix
  C = output matrix
  D = feedforward matrix
```

### STEP 2 — Key Concepts:
```
STABILITY: System is stable if ALL eigenvalues of A have negative real parts.
  → det(sI - A) = 0 → characteristic equation → same as 1 + GH = 0

CONTROLLABILITY: Can we drive the system to any state using inputs?
  → rank[B, AB, A²B, ..., A^(n-1)B] = n → fully controllable

OBSERVABILITY: Can we determine all states from outputs?
  → rank[C, CA, CA², ..., CA^(n-1)]' = n → fully observable
```

## FORMULA 1: Network Theorems

### STEP 1 — First Principles:

**Thevenin's Theorem:**
```
Any linear circuit can be replaced by:
  → Vth (open-circuit voltage) in series with → Rth (equivalent resistance)

How to find:
  1. Remove load
  2. Find V_oc at load terminals = Vth
  3. Find R_equivalent with sources zeroed = Rth
  4. I_load = Vth/(Rth + Rload)
```

**Norton's Theorem:**
```
Any linear circuit can be replaced by:
  → I_N (short-circuit current) in parallel with → R_N

How to find:
  1. Short the load terminals
  2. Find I_sc = I_N
  3. R_N = R_th
```

**Maximum Power Transfer:**
```
For DC: R_L = R_th
For AC: Z_L = Z_th* (complex conjugate)

P_max = Vth²/(4Rth)
```

### STEP 2 — Real Life Anchor:

```
Thevenin in circuits:
  → Analyzing amplifier circuits
  → Finding fault currents in power systems
  → Thevenin impedance = source impedance

Maximum power is rarely desired:
  → Efficiency = 50% at max power transfer
  → Power systems: operate at much higher efficiency
  → Audio: want loudness, not efficiency
```

### STEP 3 — Exam Form:

| Theorem | Key Formula |
|---------|-------------|
| Thevenin | Vth = Voc, Rth = Vth/Isc |
| Norton | IN = Isc, RN = Voc/Isc |
| Superposition | Sum effects of each source |
| Max Power (DC) | RL = Rth, Pmax = Vth²/(4Rth) |
| Max Power (AC) | ZL = Zth*, Pmax = \|Vth\|²/(4Rth) |

### STEP 4 — Examiner Tweaks:

| Tweak | The Trap | Counter |
|-------|----------|---------|
| 1 | "Max power at RL = Rth" | For DC only; AC = Zth* |
| 2 | "Turning off sources" | Voltage source → short; current source → open |
| 3 | "Dependent sources in Thevenin" | Don't zero them! |

### STEP 5 — Practice Questions:

**Q1 (APPSC 2018):** Find Rth for circuit with 12V source and 4Ω in series with 2Ω, all in parallel with 6Ω.

**Solution:**
```
With voltage source shorted:
  4Ω || 6Ω = (4×6)/(4+6) = 24/10 = 2.4Ω
  Plus 2Ω in series = 2.4 + 2 = 4.4Ω

  4Ω and 6Ω are in parallel: 2.4Ω
  Then in series with 2Ω: 4.4Ω
  
Rth = 4.4Ω ✓
```

## FORMULA 1B: Additional Network Theorems

### Millman's Theorem:
```
For multiple parallel branches with different voltage sources:
  → Equivalent voltage: Veq = (V1/R1 + V2/R2 + ... + Vn/Rn) / (1/R1 + 1/R2 + ... + 1/Rn)
  → Equivalent resistance: Req = 1 / (1/R1 + 1/R2 + ... + 1/Rn)

Used when: Multiple sources feed the same node through different resistors.
Example: Three generators feeding a common bus through impedances.
```

### Reciprocity Theorem:
```
In any linear bilateral network:
  → If a voltage V in branch A produces current I in branch B
  → Then the SAME voltage V placed in branch B produces the SAME current I in branch A

KEY CONDITIONS:
  ✅ Linear network only
  ✅ Bilateral elements only (R, L, C — not diodes, transistors)
  ✅ Single source at a time

🚩 EXAMINER TRAP: Only works for bilateral networks. Cannot apply to circuits with amplifiers.
```

### Dot Convention (Coupled Circuits):
```
Mutual Inductance: M = k × √(L1 × L2)   where k = coupling coefficient (0 ≤ k ≤ 1)

DOT CONVENTION RULES:
  1. Current ENTERING dotted terminal of one coil
     → Induces voltage with + at dotted terminal of other coil
  2. For series aiding (flux adds): both dots at same end
     L_total = L1 + L2 + 2M
  3. For series opposing (flux subtracts): dots at opposite ends
     L_total = L1 + L2 - 2M
  4. Turns ratio from mutual: N1/N2 = √(L1/L2)

Real-life anchor: This is why transformers have polarity markings (±).
  - Subtractive polarity: A1-a1 connected → measure A2-a2 (standard)
  - Additive polarity: A1-a2 connected → measure A2-a1 (reversed)
```

## FORMULA 2: Resonance

### STEP 1 — First Principles:

**What is resonance?**

```
In AC circuits, resonance occurs when:
  → Inductive reactance XL = Capacitive reactance XC
  → Circuit impedance is purely resistive
  → Current and voltage are IN PHASE

Series Resonance:
  Z = R + j(ωL - 1/ωC)
  At resonance: ωL = 1/ωC
  ω₀ = 1/√(LC)
```

### STEP 2 — Real Life Anchor:

```
Resonance everywhere:

1. RADIO TUNING:
   → LC circuit resonates at broadcast frequency
   → Select one station, reject others

2. INDUCTION HEATING:
   → Uses resonant circuits
   → High frequency, high power

3. POWER SYSTEM HARMONICS:
   → Resonance can amplify harmonics
   → Can cause capacitor bank failure

4. FILTERS:
   → Band-pass, band-stop using resonant circuits
```

### STEP 3 — Exam Form:

**Series Resonance:**
$$f_0 = \frac{1}{2\pi\sqrt{LC}} \text{ Hz}$$
$$Q = \frac{\omega_0 L}{R} = \frac{1}{\omega_0 RC}$$
$$BW = \frac{f_0}{Q}$$

**Parallel Resonance:**
$$f_0 \approx \frac{1}{2\pi\sqrt{LC}} \text{ (if R small)}$$
$$Q = \frac{R}{\omega_0 L} = \omega_0 RC$$

### STEP 4 — Examiner Tweaks:

| Tweak | The Trap | Counter |
|-------|----------|---------|
| 1 | "Series: max Z" | NO — minimum Z at resonance |
| 2 | "Parallel: min Z" | NO — maximum Z at resonance |
| 3 | "Q factor high = selective" | Yes, narrow bandwidth |

### STEP 5 — Practice Questions:

**Q1 (APTRANSCO 2019):** A series RLC has R = 10Ω, L = 1H, C = 100μF. Find resonant frequency and Q.

**Solution:**
```
f₀ = 1/(2π√LC) = 1/(2π√(1 × 100×10⁻⁶))
    = 1/(2π × 0.01) = 1/(0.0628) = 15.9 Hz

Q = ω₀L/R = (2π × 15.9 × 1)/10 = 100/10 = 10
```

$$P = V^2 \times \omega \times C \times \tan\delta$$

## FORMULA 3: Illumination & Specific Energy Consumption

### STEP 1 — First Principles:

**Illumination Basics:**
```
Luminous Flux (Φ): total light output — lumens (lm)
Luminous Intensity (I): light in a direction — candela (cd) = lm/sr
Illuminance (E): light falling on a surface — lux = lm/m²
Luminance (L): brightness of a surface — cd/m²

Inverse Square Law: E propto 1/d² (point source at distance d)
Lambert's Cosine Law: E propto cosθ (θ = angle of incidence)
```

**Luminous Efficacy:**
| Light Source | Efficacy (lm/W) |
|---|---|
| Incandescent | 10-15 |
| Fluorescent | 50-80 |
| LED | 100-150 |
| Sodium Vapor | 100-150 |

**Specific Energy Consumption (SEC) for Traction:**
```
SEC = Energy consumed (Wh) / [Weight (tonnes) × Distance (km)]
Units: Wh/tonne-km

Electric traction: 50-80 Wh/tonne-km
Diesel traction: 250-400 Wh/tonne-km

Lower SEC = more efficient operation.
```

### STEP 2 — Real Life Anchor:
```
Indian context:
  → Indian Railways: 25 kV AC traction, SEC ≈ 60-70 Wh/t-km
  → Street lighting: LED (100+ lm/W) replacing sodium vapor
  → Commercial buildings: target 10-15 W/m² for lighting
```

### STEP 3 — Exam Form:
```
Tractive Effort (SEC version):
  F = (eta x P x 1000) / v  (N, where P in kW, v in m/s)
  F = (375 x eta x P_hp) / V_kmh  (N)

Schedule speed = distance / (running time + stop time)
Average speed = distance / total time
V_sch < V_crest (maximum speed reached)
```

### STEP 3 — Exam Form:

**A/D Converter:**
$$Resolution = \frac{V_{fs}}{2^n - 1}$$

$$V_{out} = D \times \frac{V_{ref}}{2^n}$$

**8085 Interrupts (priority high to low):**
```
TRAP → RST 7.5 → RST 6.5 → RST 5.5 → INTR
TRAP: Non-maskable, edge+level triggered
INTR: Maskable, non-vectored
```

**8085 Addressing Modes:**
```
Direct: LDA 2000H  (3 bytes)
Register: MOV A, B  (1 byte)
Immediate: MVI A, 05H  (2 bytes)
Indirect: MOV A, M  (uses HL as pointer)
```

### Additional Digital Concepts:

**Boolean Identities:**
```
A + 0 = A, A × 1 = A, A + Ā = 1, A × Ā = 0
A + A = A, A × A = A, A + AB = A, A(A + B) = A
A + ĀB = A + B (absorption)

De Morgan's Laws:
  (A·B)' = A' + B'
  (A + B)' = A' · B'
```

**Flip-Flop Types:**
| Type | Inputs | Characteristic |
|---|---|---|
| SR | S, R | S=1 → Set; R=1 → Reset; S=R=1 → Invalid |
| JK | J, K | Like SR but J=K=1 → Toggle (no invalid state) |
| D | D | Q = D at clock edge (Data latch) |
| T | T | Toggles on each clock (Divide-by-2) |

**Schmitt Trigger:** Comparator with hysteresis (positive feedback)
  → Used for noise rejection, wave shaping, debouncing
  → Two thresholds: V_UT (upper) and V_LT (lower)

**CRO (Oscilloscope) Measurements:**
```
Voltage: peak-to-peak height × V/div
Period: horizontal distance × time/div
Frequency: f = 1/T
Phase (Lissajous): measure ellipse/pattern on screen
  → sinφ = y_intersect / y_max for ellipse aligned with axes
  → Frequency ratio = horizontal tangencies / vertical tangencies
```
