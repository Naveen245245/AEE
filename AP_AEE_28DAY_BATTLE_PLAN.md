## 📚 HOW TO USE YOUR BOOKS (Critical!)

### Made Easy (400 pages) + ACE (600 pages) = 1000 pages

**DON'T** go page-by-page (year-wise). That's a trap.

**DO** find questions TOPIC-WISE:

| Instead of… | Do this… |
|-------------|----------|
| "Solve 1995 Paper → 1996 Paper → 1997 Paper…" | Open both books. Scan the index for "Transformer OC/SC Test." Find all those questions across ALL years. Solve 8-10 of them. Done. |
| Solving every single question | Solve the representative ones. The rest are variations on the same theme. |
| Reading solutions | SOLVE FIRST. Then check. If wrong, figure out why. |

**How to identify which questions to solve within a topic:**
1. Scan the topic section quickly
2. Pick questions with DIFFERENT numerical values (different voltage levels, different %load, different pf)
3. If you see the same pattern repeated (e.g. "find efficiency at full load 0.8 pf" appears 7 times) — solve it ONCE
4. Skip identical questions
5. Always solve the question that looks "twisted" — that's the examiner trap question
