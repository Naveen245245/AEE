GATE Concepts: Per-Unit System

The Per-Unit (p.u.) system normalizes electrical quantities, simplifying network calculation across different voltage levels created by transformers.

$$\text{Value in p.u.} = \frac{\text{Actual Value (in physical units)}}{\text{Base Value (in same physical units)}}$$

Fundamental Base Formulas (3-Phase)

$$I_{base} = \frac{S_{base,3\phi}}{\sqrt{3} \cdot V_{base,LL}} \text{ (A)} \quad \text{and} \quad Z_{base} = \frac{(V_{base,LL})^2}{S_{base,3\phi}} \ (\Omega)$$

Base Conversion Formula (High-Yield GATE Equation)

$$Z_{pu,new} = Z_{pu,old} \times \left( \frac{V_{base,old}}{V_{base,new}} \right)^2 \times \left( \frac{S_{base,new}}{S_{base,old}} \right)$$

💡 GATE Exam Pro-Tips:

  • Transformer impedance p.u. remains identical whether viewed from HV side or LV side, provided their respective voltage bases follow the line-to-line transformer ratio.
  • In a 3-phase system, total 3-phase MVA base and line-to-line kV base give the exact same $Z_{base}$ as single-phase MVA base and phase kV base.

GATE Reference Summary: Fault Analysis & Sequence Connections

Symmetrical Components Transformation Matrix

$$\begin{bmatrix} I_a \\ I_b \\ I_c \end{bmatrix} = \begin{bmatrix} 1 & 1 & 1 \\ 1 & a^2 & a \\ 1 & a & a^2 \end{bmatrix} \begin{bmatrix} I_{a0} \\ I_{a1} \\ I_{a2} \end{bmatrix}, \quad a = 1\angle 120^\circ = -0.5 + j\frac{\sqrt{3}}{2}$$

Sequence Connections Rules for GATE

  • LG Fault (Phase A to Ground): All 3 sequence networks in SERIES. $$I_{a1} = I_{a2} = I_{a0} = \frac{E_a}{Z_1 + Z_2 + Z_0 + 3Z_f}, \quad I_f = 3I_{a0}$$
  • LL Fault (Phase B to C): Positive and Negative sequence networks in PARALLEL ($I_{a0} = 0$). $$I_{a1} = -I_{a2} = \frac{E_a}{Z_1 + Z_2 + Z_f}, \quad I_f = -j\sqrt{3}I_{a1}$$
  • LLG Fault (Phase B, C to Ground): Positive, Negative, and Zero sequence networks in PARALLEL. $$I_{a1} = \frac{E_a}{Z_1 + [Z_2 \parallel (Z_0 + 3Z_f)]}, \quad I_f = 3I_{a0}$$
  • 3-Phase (LLLG) Fault: Only Positive sequence network exists ($I_{a2} = 0, I_{a0} = 0$). $$I_{a1} = \frac{E_a}{Z_1 + Z_f}, \quad I_f = I_{a1}$$

1. Bus Classification in Load Flow Analysis

In power system load flow studies, each bus is associated with 4 variables: Voltage Magnitude ($|V|$), Phase Angle ($\delta$), Real Power ($P$), and Reactive Power ($Q$). Two variables are specified, and two are calculated.

Bus Type Known (Specified) Quantities Unknown (Calculated) Quantities Typical Application
Slack / Swing Bus Voltage Magnitude $|V|$, Phase Angle $\delta$ ($\delta = 0^\circ$) Real Power $P$, Reactive Power $Q$ Generator bus designated to supply system line losses. (Only 1 per system)
Generator Bus (PV Bus) Real Power $P$, Voltage Magnitude $|V|$ Phase Angle $\delta$, Reactive Power $Q$ Buses connected to generators where voltage is controlled via excitation.
Load Bus (PQ Bus) Real Power $P$, Reactive Power $Q$ Voltage Magnitude $|V|$, Phase Angle $\delta$ Substation buses supplying consumer electrical loads (80-85% of buses).

2. Y-Bus Matrix ($Y_{bus}$) Formation Rules

The admittance matrix models power transmission topology.

$$I_{bus} = Y_{bus} \cdot V_{bus}$$
  • Diagonal Element ($Y_{ii}$): Sum of all branch admittances connected directly to Bus $i$, including shunt admittances to ground. $$Y_{ii} = \sum_{k=1, k\neq i}^{n} y_{ik} + y_{i0}$$
  • Off-Diagonal Element ($Y_{ij}$): Negative of the branch admittance connected between Bus $i$ and Bus $j$. $$Y_{ij} = -y_{ij}$$
Symmetry Property: $Y_{ij} = Y_{ji}$ for reciprocal systems. $Y_{bus}$ is a highly sparse, symmetric matrix.

GATE Fundamentals: Swing Equation & Equal Area Criterion

The Swing Equation

$$M \frac{d^2\delta}{dt^2} = P_m - P_e = P_a \quad \text{or} \quad \frac{2H}{\omega_s} \frac{d^2\delta}{dt^2} = P_m - P_e$$
  • $M = \frac{J\omega_s}{10^6}$ (MJ-s/rad) : Angular momentum.
  • $H = \frac{\text{Stored Kinetic Energy at rated speed (MJ)}}{\text{Generator Rating } S_{base} \text{ (MVA)}}$ (seconds).
  • $P_a = P_m - P_e$ : Net Accelerating Power.

Equal Area Criterion (EAC) for Transient Stability

For a non-linear synchronous machine system, transient stability requires that the rotor kinetic energy gained during acceleration be dissipated during deceleration.

$$\text{Accelerating Area } A_1 = \int_{\delta_0}^{\delta_c} (P_m - P_{e,fault}) d\delta$$ $$\text{Decelerating Area } A_2 = \int_{\delta_c}^{\delta_m} (P_{e,postfault} - P_m) d\delta$$

Stability Condition: $A_2 \ge A_1$. Critical Clearing Angle ($\delta_{cc}$) occurs when $A_1 = A_2$ at maximum rotor swing $\delta_m$.
