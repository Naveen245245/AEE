AP AEE CBT — Power Electronics & Drives Quick Revision Notes

Comprehensive exam-oriented summary covering devices, converters, inverters, choppers, and drives.

1. Power Semiconductor Devices

Device Comparison Matrix

Device Control Type Carriers Switching Frequency Key Characteristic / Application
SCR (Thyristor) Current Controlled (Semi-Controlled) Bipolar Low (< 1 kHz) High power handling; turns ON by gate, turns OFF by commutation.
TRIAC Current Controlled (Bidirectional) Bipolar Low (50-400 Hz) Equivalent to 2 antiparallel SCRs; AC voltage controllers.
GTO Current Controlled (Fully Controlled) Bipolar Low to Medium (< 2 kHz) Turned OFF by applying a high negative gate current pulse.
Power MOSFET Voltage Controlled ($V_{GS}$) Unipolar (Majority) Very High (> 100 kHz) Positive temperature coefficient (easy parallel connection); low power apps.
IGBT Voltage Controlled ($V_{GE}$) Bipolar Medium to High (up to 20-50 kHz) Combines MOSFET input (high $Z_{in}$) and BJT output (low $V_{CE(sat)}$).

Static Characteristics & Protection Rules

  • Latching Current ($I_L$): Minimum gate current/anode current required to turn ON the SCR and keep it ON after gate pulse removal ($I_L > I_H$).
  • Holding Current ($I_H$): Minimum anode current below which SCR turns OFF during commutation.
  • $di/dt$ Protection: Achieved using a series inductor ($L$) to limit rapid current rise.
  • $dv/dt$ Protection: Achieved using an $RC$ Snubber Circuit connected in parallel across the SCR.

2. Phase Controlled Rectifiers & Bridge Converters

Average Output Voltage ($V_{dc}$) Formulas

Converter Type Continuous Conduction $V_{dc}$ Formula Form Factor / Key Notes
1-Phase Half Wave $\frac{V_m}{2\pi} (1 + \cos\alpha)$ (R Load) High ripple factor ($1.21$).
1-Phase Full Converter $\frac{2V_m}{\pi} \cos\alpha$ (Highly Inductive Load) Two-quadrant operation (Rectifier & Inverter modes).
1-Phase Semi Converter $\frac{V_m}{\pi} (1 + \cos\alpha)$ Single quadrant operation; higher power factor due to freewheel diode action.
3-Phase Full Converter $\frac{3V_{mL}}{\pi} \cos\alpha = \frac{3\sqrt{3}V_{m,ph}}{\pi} \cos\alpha$ 6-pulse converter; ripple frequency = $6f$.
3-Phase Semi Converter $\frac{3V_{mL}}{2\pi} (1 + \cos\alpha)$ 3-pulse converter output behavior; lower output harmonic ripple.
Effect of Source Inductance ($L_s$): Causes overlap angle ($\mu$) where incoming and outgoing SCRs conduct simultaneously. $$\Delta V_{dc} = \frac{m \cdot f \cdot L_s \cdot I_d}{\pi}$$ For a 1-phase full converter ($m=2$): $V_{dc} = \frac{2V_m}{\pi}\cos\alpha - \frac{2f L_s I_d}{\pi}$

3. DC-DC Converters (Choppers)

Duty Cycle ($\alpha$) = $T_{on} / T = T_{on} \cdot f$

Types of Basic Choppers

  • Step-Down (Buck Converter): $$V_o = \alpha \cdot V_s \quad (V_o < V_s)$$
  • Step-Up (Boost Converter): $$V_o = \frac{V_s}{1 - \alpha} \quad (V_o > V_s)$$
  • Buck-Boost Converter: $$V_o = \frac{\alpha \cdot V_s}{1 - \alpha} \quad (\text{Inverts polarity; } V_o < V_s \text{ for } \alpha < 0.5 \text{ and } V_o > V_s \text{ for } \alpha > 0.5)$$

Chopper Classifications

  • Class A: First quadrant ($V_o > 0, I_o > 0$) — Step-down chopper.
  • Class B: Second quadrant ($V_o > 0, I_o < 0$) — Regenerative braking.
  • Class C: Two-quadrant (First + Second) — Parallel combination of Class A & B.
  • Class D: Two-quadrant (First + Fourth, $I_o > 0, V_o \pm$).
  • Class E: Four-quadrant operation (All 4 quadrants).

4. Inverters (DC to AC Converters)

Voltage Source Inverters (VSI)

  • 1-Phase Full Bridge Inverter: $$V_{o1(\text{rms})} = \frac{4V_s}{\sqrt{2}\pi} = 0.9 V_s \quad (\text{Fundamental component})$$
  • 3-Phase VSI ($180^\circ$ Conduction Mode):
    • Each switch conducts for $180^\circ$; 3 switches ON at any instant.
    • RMS Line Voltage: $V_L = \sqrt{\frac{2}{3}} V_s \approx 0.816 V_s$
    • RMS Fundamental Phase Voltage: $V_{ph,1} = \frac{\sqrt{2}V_s}{\pi}$
  • 3-Phase VSI ($120^\circ$ Conduction Mode):
    • Each switch conducts for $120^\circ$; 2 switches ON at any instant.
    • RMS Line Voltage: $V_L = \frac{V_s}{\sqrt{2}} \approx 0.707 V_s$
Pulse Width Modulation (PWM):
  • Modulation Index ($m_a$): $V_{\text{control}} / V_{\text{tri}}$. Controls fundamental output amplitude.
  • Multiple PWM: Used to eliminate lower-order harmonics by controlling pulse positions.

5. Adjustable Speed DC and AC Drives

DC Drives

Speed Equation: $N \propto \frac{V_a - I_a R_a}{\Phi}$  |  Torque Equation: $T_e = K \Phi I_a$
  • Armature Voltage Control ($V_a$): Used below rated speed (Constant Torque Region).
  • Field Flux Control ($\Phi$): Used above rated speed (Constant Power Region).
  • 4-Quadrant Operation: Quadrant I (Motoring), Quadrant II (Generating/Braking), Quadrant III (Reverse Motoring), Quadrant IV (Reverse Braking).

AC Drives (Induction Motor Drives)

  • Stator Voltage Control: $T_e \propto V^2$; limited speed range due to high slip losses.
  • $V/f$ Control (Constant Volts/Hertz):
    • Keeps maximum torque constant ($T_{max} \approx \text{Constant}$) below rated speed by keeping air-gap flux constant.
    • Prevents magnetic saturation in the motor core.
  • Rotor Resistance Control: Used in Slip Ring Induction Motors; increases starting torque without drawing excessive current.
