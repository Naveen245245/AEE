2. 1-Phase Half-Bridge Inverter

Circuit Characteristics

  • DC Source: Requires a 3-wire DC supply ($V_{dc}/2$ split source across 2 equal capacitors).
  • Switches Required: 2 SCRs / Transistors ($S_1, S_2$).
  • Preventing Shoot-Through: $S_1$ and $S_2$ must **NEVER** be ON simultaneously to avoid short-circuiting the DC bus. Dead time is required.

Conduction Summary

Interval Conducting Switch Output Voltage ($v_o$) Output Current ($i_o$)
$0 \le t < \frac{T}{2}$ $S_1$ ON ($S_2$ OFF) $$+\frac{V_{dc}}{2}$$ $$+\frac{V_{dc}}{2R}$$
$\frac{T}{2} \le t < T$ $S_2$ ON ($S_1$ OFF) $$-\frac{V_{dc}}{2}$$ $$-\frac{V_{dc}}{2R}$$

Key Formulas

• RMS Output Voltage: $$V_{o(\text{rms})} = \frac{V_{dc}}{2}$$
• Fundamental RMS Voltage: $$V_{1(\text{rms})} = \frac{2 V_{dc}}{\sqrt{2} \pi} = \frac{\sqrt{2} V_{dc}}{\pi} \approx 0.45 V_{dc}$$
• Peak Blocking Voltage across OFF SCR: $$PBR = V_{dc}$$
• Output RMS Power: $$P_o = \frac{V_{o(\text{rms})}^2}{R} = \frac{V_{dc}^2}{4 R}$$

3. 1-Phase Full-Bridge Inverter

Circuit Characteristics

  • DC Source: Requires only a single standard DC supply ($V_{dc}$).
  • Switches Required: 4 SCRs / Transistors ($S_1, S_2, S_3, S_4$).
  • Diagonal Pair Operation: Switches operate in diagonal pairs ($S_1, S_2$ for $+V_{dc}$ and $S_3, S_4$ for $-V_{dc}$).

Conduction Summary

Interval Conducting Pair Output Voltage ($v_o$) Output Current ($i_o$)
$0 \le t < \frac{T}{2}$ $S_1, S_2$ ON ($S_3, S_4$ OFF) $$+V_{dc}$$ $$+\frac{V_{dc}}{R}$$
$\frac{T}{2} \le t < T$ $S_3, S_4$ ON ($S_1, S_2$ OFF) $$-V_{dc}$$ $$-\frac{V_{dc}}{R}$$

Key Formulas

• RMS Output Voltage: $$V_{o(\text{rms})} = V_{dc}$$
• Fundamental RMS Voltage: $$V_{1(\text{rms})} = \frac{4 V_{dc}}{\sqrt{2} \pi} = \frac{2\sqrt{2} V_{dc}}{\pi} \approx 0.90 V_{dc}$$
• Peak Blocking Voltage across OFF SCR: $$PBR = V_{dc}$$
• Output RMS Power: $$P_o = \frac{V_{o(\text{rms})}^2}{R} = \frac{V_{dc}^2}{R}$$

4. Comparison Matrix & Fourier Harmonic Analysis

Fourier Expansion of Square Wave Output

Full Bridge: $$v_o(t) = \sum_{n=1,3,5\dots}^{\infty} \frac{4 V_{dc}}{n \pi} \sin(n \omega t)$$
Half Bridge: $$v_o(t) = \sum_{n=1,3,5\dots}^{\infty} \frac{2 V_{dc}}{n \pi} \sin(n \omega t)$$
  • Contains only odd harmonics ($n = 1, 3, 5, 7 \dots$).
  • Lowest dominant harmonic is the 3rd harmonic ($n = 3$).
  • Total Harmonic Distortion (THD) of ideal square wave output = **48.34%**.
