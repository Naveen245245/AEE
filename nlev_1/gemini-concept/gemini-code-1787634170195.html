2. Thyristor Chopper Commutation Techniques

Commutation Type Mechanism & Circuit Operation Key Formulas & Turn-Off Time ($t_c$) GATE / AE Key Features
Voltage Commutated
(Impulse Commutated)		 • Aux SCR ($T_A$) is triggered to connect pre-charged reverse capacitor voltage across Main SCR ($T_1$).
• $T_1$ is reverse-biased & turns off instantly. 		$$t_c = \frac{C \cdot V_s}{I_o}$$
Peak $T_1$ Current: $I_{T1(\max)} = I_o + V_s \sqrt{\frac{C}{L}}$ 		• Highly reliable.
• Drawback: Capacitor must be pre-charged prior to main operation; $T_1$ carries additional resonant current pulse.
Current Commutated
(Resonant Commutated)		 • $T_A$ is triggered to initiate a resonant LC pulse opposing the load current through $T_1$.
• Current through $T_1$ is forced down to zero. 		$$t_c = \omega_0 \cdot C \cdot V_s / I_o$$
Resonant Frequency: $\omega_0 = \frac{1}{\sqrt{LC}}$
Peak Resonant Current: $I_p = V_s \sqrt{\frac{C}{L}} > I_o$ 		• $T_1$ turns off when current hits 0 (Soft Commutation).
• Commutation capacitor voltage does not depend on load current.
Load Commutated
(Self Commutated)		 • Load current flows directly through commutating capacitor $C$.
• As $C$ charges up to $V_s$, current drops below holding current ($I_H$), turning SCR off automatically. 		$$t_c = \frac{R L C \text{ network parameters}}{I_o}$$
$$V_{c(\max)} = V_s + I_o \sqrt{L/C}$$ 		• No auxiliary SCR needed.
• Used in high frequency series inverter & chopper applications.

3. Chopper Classifications (Quadrants)

Class Voltage / Current Polarity Quadrant(s) Application / Operation
Class A $V_o > 0, I_o > 0$ First ($Q_1$) Motoring mode (Power flows Source $\to$ Load).
Class B $V_o > 0, I_o < 0$ Second ($Q_2$) Regenerative Braking (Load $\to$ Source).
Class C $V_o > 0, I_o \pm$ First & Second ($Q_1, Q_2$) Combined Motoring & Regenerative Braking.
Class D $V_o \pm, I_o > 0$ First & Fourth ($Q_1, Q_4$) Two-quadrant with reversible output voltage.
Class E $V_o \pm, I_o \pm$ All Four Quadrants 4-Quadrant DC Drive Speed/Direction Control.

4. Chopper Control Strategies

Average Output Voltage: $V_o = \alpha \cdot V_s = \frac{T_{on}}{T_{on} + T_{off}} \cdot V_s = f \cdot T_{on} \cdot V_s$
  • Time Ratio Control (TRC) — Constant Frequency (PWM): Chopping period $T$ ($1/f$) remains fixed, while $T_{on}$ is modulated. Best for harmonic filter design.
  • Time Ratio Control (TRC) — Variable Frequency (FM): $T_{on}$ kept constant while $T$ varies (or vice-versa). Creates sub-harmonic noise issues.
  • Current Limit Control (CLC): Chopper turns ON when load current drops below lower limit $I_{min}$ and turns OFF when current touches upper limit $I_{max}$.
